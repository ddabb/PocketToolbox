# 1.3.5 开发计划：日语支持

## 背景
1.3.4 已落地中英双语（`zh` 限定词目录 + `base` 英文兜底，883 键）。用户选定日语作为第三语言：内容契合度最高（漢詩/成語文化亲近）、汉字混排协调、引号风格一致（「」）、无 RTL 问题。

## 方案
- 新增 `entry/src/main/resources/ja/element/string.json`，883 键全量日语化，键集合与 zh/base 严格一致
- 语言跟随系统（`ja` 匹配所有 ja-* 变体）；无应用内切换器
- **不译**（与 1.3.4 决策一致）：品牌名「解语珠玑」（保留简体原样，不作「解語珠璣」字形转换）、诗词/成语/歇后语内容本体、字体族名、示例内容、数据域值
- 代码零改动：资源解析按系统 locale 自动匹配；`StrUtil`/`getStringByNameSync` 与语言无关

## 流程
1. 提取 883 键（key/zh/en），按语义前缀切 6 块
2. 6 个并行子代理按术语表翻译 → 块级 JSON 报告
3. 校验：键序一致、占位符集合与 zh 一致（%1$s 可换位）、ja 非空、总数 883
4. 按 zh 键序组装 `ja/element/string.json`，人工抽查译文
5. 三语言键集合 parity 校验 + 构建
6. 版本 1.3.5/1000015，单行提交

## 验收标准
- `ja` 与 `zh`/`base` 键集合完全一致（883 键）
- 所有格式化键（%n$s/%n$d）参数集合跨语言一致
- 构建 SUCCESS；系统语言切日语后 UI 全日语（内容域除外）
- 品牌、字体名、内容保持原文
