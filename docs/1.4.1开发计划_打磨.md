## 测试期缺陷修复（模拟器复现验证）
1. **首页-每日挑战-诗词填空底部截断**
   - 根因：页面主内容列与 QuestionSection 根列均固定 `height('100%')` 且无 Scroll；4 张入口卡 + 题卡 + 3 选项超出可视区，第 3 选项（C）及答题反馈被整体裁剪（bounds 约在 Tab 栏之下）
   - 修复：主内容包 `Scroll`（显式 `.align(Alignment.Top)` 防 Scroll 默认居中），去掉两处固定高；ResultSection 去内层 Scroll 防嵌套；loading 块 layoutWeight 改固定高
   - 验证：滑动后 C 选项完整可见；点选后 ✓ 反馈正常
2. **工具-GIF制作-参数点击无响应（倍速/播放模式/循环播放/输出尺寸/画质）**
   - 根因：`OptionChips` @Builder 按值传参 `selected`，高亮样式读参数而非 @State——点击后状态已变但 UI 不重绘，视觉上"点了没反应"（@Builder 参数不参与依赖追踪）
   - 修复：改传 `kind` 常量，Builder 内部经 paramChipSelected()/pickParamChip() 直读 @State；共 7 处调用点（含视频帧率、贴纸分类）
   - 验证：点「2x」「3次」「720P」后像素采样确认高亮移至目标 chip（idiom_blue #21689e），原选中恢复未选

## 生字卡专项（拼音渲染问题排查 + 两项改进）

### 拼音声调字符变数字串问题（用户真机截图 docs/拼音不对.png）
- 现象：导出图拼音行 "ā ér bù yě" 中 Ext-A 声调字符变成码点数字（282=U+011A Ě、258=U+0102 Ă、283=U+011B ě），Latin-1 的 ù（bù）正常
- 排查结论（全部排除，模拟器不可复现）：
  - 库无损：node 直跑 pinyin-pro 输出正确；.mjs 为预合成码点（U+011B=UTF-8 C4 9B，此前误查 C7 9B 是 Ǜ）
  - 构建无损：modules.abc 内拼音字典声调字符计数与 .mjs 一致（ā 1758/1799、ǒ 363/368、ǔ 508/532、ē 728/744）
  - 字体无损：hap 内打包 LXGWWenKaiLite-Regular.ttf cmap 25598 码点，含全部拼音声调字符
  - 渲染无损：模拟器同输入「阿而不也」同配色，预览 dump 字符串正确、导出 PNG 像素分析四槽声调符（ā macron/ér acute/ù/ě caron）全部正常
  - 导出管线：导出=组件快照（getComponentSnapshot），与预览同一渲染路径，无独立绘制/转义环节
- 结论：真机特有的字体回退/渲染问题（楷体字体在该设备上对 Latin Ext-A 声调字符做了码点数字化回退），无法本地复现根因
- 兜底修复：拼音 Text 去掉 `.fontFamily(楷体)` 改系统默认字体（诗词页 PinyinText 同策略先例）；汉字仍用楷体；系统字体声调字符零风险
- 验证：docs/生字卡_方卡导出_拼音声调修复验证.png（1080x1080，阿而不也，ā/ér/bù/yě 四槽声调符像素级确认）
