# 1.3.8 开发计划：飞花令 · 诗词注音 · 数据备份

> 主题「学得深、带得走」：一个差异化练习功能 + 一个低成本补深 + 一个付费上架前的信任基建。全程离线。

## B 数据导出/导入（信任基建）
- **范围**：三个 Preferences 文件通用全量导出 `app_cache`（收藏/签到/成就/生字簿/粘性统计）、`reading_lists`（阅读清单）、`reading_settings`（朗读设置）
- **方案**：`getAllSync()` 整表 dump，不做逐键语义解析；导入按"备份优先"恢复语义（备份中存在的键覆盖本地，不存在的保留），导入前 AlertDialog 二次确认
- **文件格式**：`{ "app": "com.ddabb.toolbox", "format": 1, "exportedAt": <ms>, "prefs": { "<name>": { "<key>": <value> } } }`，文件名 `PocketToolbox备份_<yyyyMMdd_HHmmss>.json`
- **IO**：@kit.CoreFileKit DocumentViewPicker（保存/选择，免权限）+ fs 读写
- **UI**：我的页新增「数据备份」入口 → DataBackupPage（导出按钮 / 导入按钮 / 数据范围说明 / 结果反馈）
- **边界**：导入校验 format 与 app 标识，非法文件报错不落地；导出失败（用户取消/IO异常）toast 提示

## A3 诗词注音（补深）

- 新组件 PinyinText：逐字「拼音在上、汉字在下」排版，复用 `CoverContentUtil.autoPinyin` 引擎；处理标点（无拼音占位）与换行
- 不动 PoetryDetailPage 列表态，只做阅读态

## A1 飞花令（差异化练习）
- **数据预计算**（Node 脚本，构建期一次性）：从 `rawfile/poetry/*.json` 抽取诗行，按令字建索引；令字表约 30 个高频字（花月风雪山江水云春夜酒楼…）；每字收录 ≤400 句（去重、含出处 title/author/line），输出 `rawfile/flyflower/lines.json`（目标 <600KB）
- **玩法**：抽令字 → 用户输入含该字的诗句 → 去标点后与索引行精确匹配 → 有效则连对+1 并入历史（显示出处），无效提示（未含字/不在库中/已用过）；连对中断条件：主动结束或切换令字；「换一字」重新开始；「提示」揭示一个未用句的首字
- **页面**：FlyFlowerPage；入口放 DailyChallengePage 顶部模式卡；Index PageMap 注册路由
- **记录与成就**：StickinessUtil 新增 `flyflower_best_streak`（最佳连对）与 `flyflower_total`（累计有效句）；新增 2~3 枚成就（首对/连对10/连对30），三语
