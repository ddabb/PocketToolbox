# 1.4.0 开发计划：错题本 · 间隔复习

> 主题「复习闭环」：1.3.9 默写产生学习行为数据，1.4.0 把数据变成复习资产——练→错→再练→按遗忘曲线巩固。全程离线。
> 备注：应用已切换整包付费（2026-10 确认），本版起规划只做功能。

## 核心数据层：SentenceRecord（错题本与复习队列同源）
- **存储**：prefs `app_cache` 文件新键 `sentence_records`，JSON 数组，上限 300 条（淘汰规则：先淘汰已毕业且无错字的，再淘汰最旧）；**备份导出导入自动覆盖（BackupUtil 通用 dump，零改动）**
- **记录粒度**：句+字两级——句子档案含错字索引数组（用户已拍板）
- **字段**：key（诗名|作者|句子）、poemName/poemAuthor/poemDynasty、raw、wrongChars[]、errCount、lastWrongAt、reviewStage（梯度索引 0~4）、nextReviewAt（0=未排期/已毕业）、createdAt
- **梯度**：[1, 2, 4, 7, 15] 天；判定完美 → stage+1、next=now+下一档（stage 4 完美 → nextReviewAt=0 毕业，不再入队）；非完美 → wrongChars 合并去重、errCount+1、stage=0、next=now+1天
- **信号**：每次写入后 `AppStorage('ReviewDataVersion')` 递增，消费方用 `@StorageLink + @Watch`（项目已有 ReadingDataVersion 惯例）

## A1 错题本（MistakeBookPage）
- 列表：错句卡片（句子文本、错字标红、出处、错误次数），按 lastWrongAt 倒序；空态引导去默写
- **页内重练**：单句挖空——**错字优先被挖**（wrongChars 全挖，不足策略数随机补足），复用 `DictationUtil.buildSentenceWithBlanks(raw, preferIdx)`（新扩展，原 buildSentence 委托它）
- 判定全对 → 移出错题本（toast 已消灭）；非全对 → 更新档案；「下一个」顺序练完整本
- 入口：挑战页入口卡（M 句）

## A2 间隔复习（ReviewPage）
- **对象**：仅默写练过的句子（用户已拍板）；默写页每次判定（不限首次）调用 `ReviewStore.recordResult` 自动排期
- 队列：nextReviewAt ≤ now 的记录，按到期升序；「开始复习」逐句挖空（错字优先）判定
- **自评自动化**（简化说明）：判定结果即自评——完美=记得（梯度进阶）、非完美=模糊（梯度重置），无手动自评 UI，减少摩擦
- 完成态：「今日复习完成」+ 已消灭/进行中统计；复习判定同样计入 Stickiness（新增 `reviewTotal` + `recordReviewSentence` + 成就 2 枚：review_first 温故知新 / review_30 学而时习）
- 入口：挑战页「今日复习 N 项」卡（N=0 显示已完成今日复习）

## A3 复习提醒通知（ReviewReminderUtil）
- 新建 `ReviewReminderUtil`（复制 CheckInReminderUtil 已验证模式：ReminderAgentManager 闹钟 + 通知授权流程 + 开关持久化），每日 19:30（错开签到提醒 20:00 防连响），文案 `reminder_review_content`
- 开关放 ReviewPage 顶部行；my 页/关于页不动

## 接线与入口
- DictationPage.submitSentence 判定后收集错字索引调用 `ReviewStore.recordResult(ctx, poem, raw, wrongIdx, perfect)`（每次判定都调用，upsert 语义；Stickiness 统计维持仅首次不变）
- 挑战页：默写卡下方新增「今日复习 N 项」+「错题本 M 句」两卡，`@StorageLink('ReviewDataVersion') @Watch` 实时刷新
- router_map + Index PageMap 注册 MistakeBookPage、ReviewPage
