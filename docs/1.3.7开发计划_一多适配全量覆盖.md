# 1.3.7 开发计划：一多适配全量覆盖

> 1.3.6 B 档仅覆盖首页工具网格 + 4 个关键页；本期将 maxWidth 约束范式推广到全部 NavDestination 页面，并做首页「每日内容」卡片响应式三列。

## 范式（继承 1.3.6 B 档，已验证）
- **A 根有背景**：内容包一层 `constraintSize({maxWidth})` 内列，背景留根容器全屏（PoetryDetailPage 范式）
- **B 根无背景**：根容器直接加 `constraintSize`（CoverMakerPage 范式）
- **C Stack 根**：背景上移 Stack，主内容列加约束（ReadingPlayerPage 范式）
- **D NavDestination 无背景**：背景加到 NavDestination，内容根加约束（UnitConverterPage 范式）

## 页面清单与 maxWidth
| 批次 | 页面 | maxWidth |

| 1 查询/详情 | PoetryQuery / IdiomQuery / XiehouyuQuery / PoemContent / Favorites / About | 720 |

## 约束
- 手机（≤600vp）布局零变化（maxWidth 均 >600）
- 不改逻辑/文案/颜色；不动 NavDestination 标题栏（约束只作用于内容）
- CharCardPage / WordCloudPage 已有深色 mediaquery 与预览尺寸逻辑，只补内容列约束

## 验收
- 全部页面宽屏内容居中不拉伸；手机无回退；构建 SUCCESS

## 实现记录（2026-10-05）
- 全部 20 文件落地，实际改动 +60/-11 行，arkts_check 20/20 通过，构建 SUCCESS（58.8s）
- 范式分布：A 包装列（Idiom/Xiehouyu/Favorites/About/GifMaker/DailyChallenge/Sudoku顶栏）；B 根列直接约束（CharCard）；C Stack 接管背景+主列约束（PoetryQuery/PoemContent/ReadingList/TimezoneConverter/Md2Png）；D 背景上移 NavDestination+Scroll 根约束（UnitCategory/BaseConverter/GcdLcm/PrimeFactor/WordCloud/Achievement）
- 特殊处理：Sudoku 粘贴弹窗 `#00000080` 遮罩为内层 Stack 子节点，仅约束 TopBar/消息列与棋盘 Scroll，遮罩保持全屏；所有 bindContentCover/AlertDialog/浮层（OCR、城市选择、生字簿、列表弹窗）均未约束
- 关键依据：通用属性 `align` 默认 `Alignment.Center`（common.d.ts），Scroll/Stack 内子列加 constraintSize 即自动水平居中
- 已知取舍：范式D 页面 NavDestination 标题栏底色变为 page_background（与 1.3.6 UnitConverterPage 先例一致，视觉无缝）；批次1 大 diff 为包装列整体缩进（--ignore-all-space 后每页仅 +5 行）
- 手机路径零变化承诺：全部约束 maxWidth 均 >600vp，<720/760vp 屏宽下为 no-op；背景迁移前后覆盖区域均为全屏
