# 生字卡独立工具 与 图片生成功能规划 需求文档

> **文档状态：已批准（2026-09-16，PDCA 开发验收启动）** | 日期 2026-09-16 | 作者：产品经理（AI 代笔）
> 前置文档：《公众号首图制作需求文档》（已批准 v1.1，含旗舰模板 B5 田字格字卡）。
> 本文档两部分：**第一部分**为「生字卡」独立工具的详细需求（P0）；**第二部分**为图片生成功能矩阵与路线图（P1/P2 规划）。

---

## 1. 背景与目标

### 1.1 背景
- 公众号首图功能（开发中）已实现 B5「田字格字卡」：900×383 横幅、蓝底、自动注音、红色田字格。PM 评审结论（2026-09-16）：
  - 生字卡的真实主场景是**语文老师课堂展示**与**家长辅导/分享**（家长群、朋友圈），而非公众号封面；900×383 横幅比例对主场景并不合适；
  - 「公众号首图」的命名把工具框窄了，生字卡应独立成工具、按主场景选择比例；
  - 上一版 PRD 决策「1:1 次图本期不做，后续重新立项」——本文档即为该场景的重新立项。
- 应用已有可复用基建：B5 渲染布局（田字格/注音）、pinyin-pro 自动注音、md2png 组件截图导出管线、字体资产、制作历史存储。

### 1.2 目标
- **P0（本期）**：上线独立的「生字卡」工具——选比例 → 输入整课生字 → 自动注音 → 单卡/批量导出，单卡制作 ≤30 秒，整课（8 字）批量导出 ≤10 秒。
- **规划**：确立图片生成功能矩阵，明确 P1 立项顺序（日签 → 注音短文图 → 诗词长图），避免功能散点开发。

### 1.3 非目标（本期不做）
- 不做笔顺动画/笔顺静态分解（需 hanzi-writer 数据包 ≥10MB，放 P2 重新评估）；
- 不做组词、部首、笔画数等拓展信息（需新数据源，P2）；
- 不做 A4 整页字帖排版（归入 P2「描红字帖」候选）；
- 不移除首图制作中的 B5 模板（公众号封面场景仍需要它，见 §3.1）。

## 3. 功能需求：生字卡独立工具（P0）

### 3.1 入口与关系
- 工具页「创作」分类新增卡片：**生字卡**，描述「田字格生字卡，一键注音」（不新建「语文」分类，避免单工具成类，见 §9 待确认 D1）；
- **B5 模板保留在首图制作中**：公众号封面场景继续可用；生字卡工具与 B5 共享渲染实现，但入口、页面、历史相互独立；
- 生字卡工具定位为「教学/分享」：比例、格型、批量能力均以课堂与家长场景为准。

### 3.2 页面结构
单页三段式（与首图制作同构）：
1. **预览区**：实时预览当前卡，比例随所选尺寸切换；
2. **尺寸/格型横滑条**：尺寸 2 档 + 格型 2 档 + 配色 chips；
3. **内容编辑区**：生字输入框（1-12 字）+ 拼音行（自动/锁定/开关）+ 批量导出栏 + 历史区（最近 20 条）。

### 3.3 尺寸规格（P0 两档）
| 档位 | 像素 | 比例 | 主场景 |
|---|---|---|---|
| 方卡（默认） | 1080×1080 | 1:1 | 投屏、家长群、朋友圈 |
| 练习卡 | 1080×1440 | 3:4 | 打印、描红练习 |

- 预览按设计稿等比渲染（方卡设计稿 900×900，练习卡 900×1200），导出快照 scale 动态计算保证像素精确。

### 3.4 卡面样式
**格型（2 种，P0）**：
| 格型 | 描述 |
|---|---|
| 田字格（默认） | 外框实线 + 十字虚线，同 B5 规格 |
| 米字格 | 外框实线 + 十字虚线 + 对角虚线（斜线 alpha 降低），书法练习感 |

**字色模式（2 种，P0）**：
| 模式 | 描述 |
|---|---|
| 认读（默认） | 楷体黑字（霞鹜文楷），字号约格宽 70% |
| 描红 | 楷体 30% 透明度浅灰字，供打印后描红 |

**格数自适应**：1-8 字一行自适应等距居中（沿用 B5 公式）；>8 字（≤12）时两行排布，行间距同列间距。方卡设计稿基准：1 字格边 320，4 字格边 170，8 字格边 90，按公式缩放。

**配色（P0 5 套）**：蓝底红格黑字（默认，同 B5）、米白底红格黑字、黑板绿底米格白字、暗红底米格黑字、米白底墨格墨字。

### 3.5 拼音
- 沿用 B5 逻辑：由生字**自动注音**（pinyin-pro，带调），实时更新；手动修改即锁定，提供「恢复自动」；
- 新增**拼音开关**：关闭后卡面只保留田字格与生字（部分老师偏好无拼音版本做测验）；
- 拼音位置：格区上方居中；两行生字时拼音跟随各自行上方。

### 3.6 批量导出（差异化核心，P0）
- 输入 2-12 个生字 → 预览区默认显示第一张卡，可左右滑动逐张检查；
- 「全部导出」：按序渲染每字一卡（每卡自动注音），逐张保存到相册，显示进度（如 3/8）；
- 中途可取消；完成后 Toast「已保存 8 张到相册」；
- 单卡「保存/分享」能力不变（复用现有 ShareImageUtil）。

### 3.7 制作历史（P1）
- 最近 20 条记录（缩略图 + 字 + 尺寸 + 时间），点击恢复编辑；
- 存储复用 CoverHistoryStore 模式，独立目录 `card_history`。

## 4. 图片生成功能矩阵与路线图（规划部分）

### 4.1 矩阵总览
按「目标人群 × 现有资产复用度 × 差异化」评估：

| 功能 | 一句话定义 | 人群 | 资产复用 | 差异化 | 优先级 |
|---|---|---|---|---|---|
| 生字卡 | 田字格生字卡批量制作 | 老师/家长 | B5+注音+管线，极高 | 强 | **P0 本期** |
| 日签（每日一图） | 今日诗词+日期节气，竖版分享图 | 全体用户 | 内容库+管线，极高 | 中 | **P1-1** |
| 注音短文图 | 整段文字自动注音（逐字 ruby），导出长图 | 老师/家长 | pinyin-pro+管线，高 | 强 | **P1-2** |
| 诗词长图（诗笺） | 整首诗仿古排版长图，可从诗词详情页直达 | 创作者/用户 | 内容库+竖排+管线，高 | 中 | **P1-3** |
| 奖状生成 | 背诵/写字奖状，毛笔字+印章 | 老师/家长 | 字体+印章+管线，中 | 中 | P2 |
| 描红字帖 | A4 整页多字字帖（生字卡延伸） | 老师/家长 | 生字卡延伸，中 | 中 | P2 |
| 节气海报 | 节气自动上新海报 | 创作者 | 并入日签场景 | 弱 | P2（并入日签） |
| 文字表情包 | 斗图文字贴 | 泛用户 | 字体 | 弱（同质化） | 暂缓 |
| 二维码美化 | 古风二维码 | 创作者 | 低 | 弱（同质化） | 暂缓 |

### 4.2 P1-1 日签（预估 2 人天）
- **定义**：打开即见今日一张 3:4 竖版卡片——今日诗词（与首页「每日诗词」同源同种子，保证当日一致）+ 公历日期 + 农历/节气（如可得）+ 应用印章；
- **入口**：首页每日诗词卡新增「生成日签」按钮 + 工具页创作分类入口；
- **规格**：1080×1440；2 套模板（宣纸竖排 / 简约横排）；配色 4 套；
- **价值**：给用户每日打开理由，导出图自带应用气质，是最低成本的传播物料；
- **边界**：不做自定义文案（v1 固定今日诗词）；农历/节气数据源需确认（无则只显示公历日期）。

### 4.3 P1-2 注音短文图（预估 3 人天）
- **定义**：粘贴 ≤200 字短文 → 逐字自动注音（pinyin-pro `type:'array'` 逐字取音）→ ruby 排版（拼音小字在上、汉字在下）→ 选字体/纸纹 → 导出长图（宽 1080，高度自适应）；
- **人群**：语文老师做注音阅读材料、低年级家长做儿歌/短文；
- **模板**：2 套（米白纸纹 / 黑板绿）；字号 2 档；
- **技术风险**：ArkUI 无原生 ruby 排版，需自定义「逐字 Column(拼音,汉字) + Flex 换行」实现，多音字按词消歧；M 首日先做排版验证；
- **边界**：不做逐字点击改音（锁定 pinyin-pro 结果）；英文/数字原样不注音。

### 4.4 P1-3 诗词长图·诗笺（预估 2.5 人天）
- **定义**：选一首诗 → 整首仿古排版（诗题/作者/正文/印章）→ 导出竖版长图；
- **入口**：诗词详情页新增「生成长图」按钮 + 工具页入口；
- **规格**：1080×高度自适应（≤4 屏）；竖排（复用 B1 竖排实现）与横排 2 套模板；纸纹底 3 选 1；
- **价值**：与首图（封面）、生字卡（教学）形成创作者内容生产闭环；
- **边界**：长诗自动缩字号不自动分页（超 4 屏提示截取）；不做繁体转换（P2）。

### 4.5 P2 候选（本期只立项不排期）
- **奖状生成**：3-4 套奖状模板（背诵达人/写字之星/进步之星），毛笔字标题+姓名手填+印章+日期；
- **描红字帖**：A4 比例（2480×3508）整页，每行 N 格 + 首格示范字 + 余格描红/空格，从生字卡「字帖模式」进入；
- **E1 相册底图**：承接首图制作 P1 遗留项，一并评估相册权限。

## 5. 技术方案概要（生字卡 P0）

- **复用**：CoverPreview 中 B5 的 GridCell/注音布局抽取为共享 Builder；CoverContentUtil.autoPinyin、CoverHistoryStore 模式、md2png 快照导出管线直接复用；
- **新增文件预估**：`core/cover/CharCardTemplates.ets`（尺寸/格型/配色常量）、`pages/CharCardPage.ets`（页面+批量导出循环），约 800-1000 行；
- **批量导出实现**：循环「设置当前字 → 等待渲染完成 → 快照 → 保存」，快照 scale 按所选尺寸动态计算；进度用 @State 驱动；
- **两行布局**：>8 字时格矩阵按 2 行排布，拼音按行分组注音。

## 6. 测试策略（生字卡 P0）

- 单元测试：尺寸档位常量、格数自适应公式（1/4/8/12 字居中与两行切换）、批量注音逐字正确（「学而时习之」5 字各卡拼音独立正确）、历史存取；
- UI 测试：单卡导出 1080×1080 精确、批量 8 字导出 8 张、拼音开关、描红模式、深色模式；
- 验收基准见 §7。

## 7. 验收标准（生字卡 P0）

1. 工具页创作分类可见「生字卡」入口；首图制作 B5 不受影响；
2. 单卡导出像素精确：方卡 1080×1080、练习卡 1080×1440，PNG；
3. 「学」单字卡自动注音为 `xué`；批量「春夏秋冬」4 卡拼音分别为 `chūn/xià/qiū/dōng`；
4. 输入 12 字时两行排布，格区水平居中、拼音各行上方对齐；
5. 批量导出 8 字 ≤10s，进度可见，全部入相册，无缺张；
6. 拼音开关关闭后卡面无拼音；描红模式字为约 30% 透明度；
7. 米字格含对角虚线且视觉弱于十字线；
8. 深色模式下编辑界面无不可见文字。

## 10. 验收记录（2026-09-17，Huawei_Phone 模拟器 API 19 实测）

### 通过项
- 工具页「创作」分类入口、页面加载正常；
- 尺寸（方卡 1:1 / 练习卡 3:4）、格型（田字格/米字格，米字格对角线弱化）、字色（认读/描红）、拼音显示/隐藏、5 套配色全部可用；
- 1-12 字自适应：5 字与 4 字两档数值验证（格间距均匀、拼音槽与格子中心偏差 0.5px）；
- **拼音逐字对齐**（本轮新增验收项）：每音节槽宽=格边长、槽距=格间距，与格子几何完全一致；音节数与字数不符时回退整行居中；长音节自动缩字号防截断；
- 拼音锁定/恢复自动焦点守卫（手动编辑不覆盖、追加字符自动同步、整课替换联动）；
- 批量导出单弹窗架构（逐字渲染落盘 → 历史 → 单次系统弹窗 → finally 清理临时文件）；
- 历史记录创建与恢复、目录隔离（card_history）；
- 分享面板拉起正常（华为分享/复制/保存至图库/打印/添加至中转站）；
- 8 用例单元测试通过，构建/安装/启动正常。

### 受限项（系统级缺陷，非应用问题）
- 验收标准 §7 第 5 条「全部入相册无缺张」：API 19 模拟器（5.1.0.235）`photoAccessHelper.getPhotoAccessHelper()` 返回 undefined（探针实证），保存相册必失败。应用已实现**诚实失败**：toast「导出失败：系统相册服务不可用」，绝不虚报成功；历史记录在失败前正常创建。真机验证待定。

### 技术债
- 其余 5 处旧保存调用点（GifMakerPage/Md2PngPage/ShareImageCard/ImageSaveShareBar 内联代码）仍为静默失败+假 toast 模式，待统一迁移至 ShareImageUtil 新接口；
- 深色模式编辑界面验收待补。

### 决策补充
- 暗红/黑板绿配色字与拼音用米白 #F0EAD8（PRD 原写黑字，对比度不足，已按实际实现修正）。
