# 公众号首图制作需求文档

> **文档状态：已批准（v1.1 修订版）** | 日期 2026-09-16 | 作者：产品经理（AI 代笔）
> v1.1 修订：合并《公众号首图封面需求文档》参考需求，固化为旗舰模板 B5 田字格字卡；确认决策：不做 1:1 次图、E1 相册底图放 P1、首版模板 15+1 个。

## 1. 背景与目标

### 1.1 背景
- 公众号运营者/自媒体作者每周都需要制作文章封面图（首图），现状是依赖 Canva/稿定设计等在线工具或设计师，流程重、启动慢、模板偏商业风。
- 本应用「解语珠玑」已有成熟的内容资产与渲染基建，与本需求高度复用：
  - **字体资产**：rawfile 内置 10 款开源中文字体（霞鹜文楷、站酷庆科黄油体、站酷小薇、马善政楷书、龙藏体、柳建毛草、智麻行书、思源黑体等）；
  - **内容资产**：诗词库（index.json）、成语库（idiom.json）、歇后语库；
  - **渲染基建**：md2png（文字转图片）已具备模板系统、组件渲染截图、保存相册、分享能力。
- 原始参考需求（已合并进本文档）：语文教育类运营者需要生成「生字卡」式封面——蓝底、顶部拼音、一行红色田字格内楷体大字（如「学而时习之」）。该场景已固化为旗舰模板 **B5 田字格字卡**（详见 §4.6）。
- 「文字转图片」偏长文排版，而首图是**大字海报式**排版，二者场景不同，值得独立成工具。

### 1.2 目标
- 让用户在手机上 **30 秒内**产出一张专业感的公众号封面图：选模板 → 填文字 → 导出。
- 差异化：依托本应用独有的**诗词/成语/歇后语内容库**，提供「文化内容系」模板，一键取用今日诗词作为封面文案 — 这是 Canva 类工具不具备的。
- P0 版本即提供 **16 个精选模板（15 个 + 参考需求合并的田字格字卡）× 每模板 4-6 套配色**，开箱即用。

### 1.3 非目标（本期不做）
- 不做多人协作、云端模板商店；
- 不做复杂图层/自由排版编辑器（区别于 Canva）；
- 不做视频封面、小红书封面等多规格（远期 P2 再议）；
- 不做 AI 生成文案（远期 P2）。

| 场景 | 用户行为 | 产物 |
|---|---|---|
| S1 日常更文 | 填标题+公众号名 → 选一个常用模板 → 导出 | 900×383 封面 |

## 3. 功能需求

### 3.1 工具入口（P0）
- 工具页「创作」分类新增卡片：**首图制作**，描述「公众号封面 30 秒出图」，与词云/文字转图片/GIF 制作并列。

### 3.2 页面结构（P0）
单页三段式（自上而下）：
1. **预览区**：实时预览，比例 2.35:1，所见即所得；
2. **模板横滑条**：模板缩略图横向滚动选择，按系列分组标签（简约/文化/大字/杂志/图片）；
3. **内容与样式编辑区**：Tab 切换「文字 / 样式」。

### 3.3 内容槽位系统（P0）
模板由槽位（Slot）组成，不同模板启用不同槽位：

| 槽位 | 说明 | 必填 |
|---|---|---|
| 主标题 | 封面大字，支持 1-2 行，自动缩放字号防溢出 | 是 |
| 副标题 | 补充说明小字 | 否 |
| 署名 | 公众号名/作者，常驻角落 | 否 |
| 期号/日期 | 如「第 42 期」「2026.09.16」，可自动填充今日日期 | 否 |
| 引言 | 文化系模板的诗句/成语正文 | 否 |
| 拼音 | 生字卡模板顶部注音，**由生字自动注音生成**（可手动修改），带音调字符（如 `xué ér shí xí zhī`） | 仅 B5 必填 |
| 印章 | 2-4 字方形红印（如「珠玑」），杂志系/文化系启用 | 否 |

- 所有槽位在预览中**点击即定位**到对应输入框。

### 3.4 内容库联动（P0，差异化核心）
- 文化系模板提供「**换一句**」按钮：从诗词/成语/歇后语库随机推荐一条（含出处），一键填入引言槽位、出处填入副标题；
- 记录已推荐内容，同一次会话内不重复；
- 输入框支持手动输入，不受联动限制；
- **自动注音（P0）**：B5 生字卡模板中拼音由生字内容**自动生成**（ohpm 三方库 `pinyin-pro`，支持音调符号 `xué ér shí xí zhī` 与多音字智能消歧），生成结果可手动修改覆盖。

### 3.5 样式自定义（P0）
- **配色方案**：每个模板内置 4-6 套配色（含深浅两版基底），一键切换；
- **字体**：主标题可在 4-6 款与模板气质匹配的字体中切换（模板有推荐默认字体）；
- 深色模式下编辑界面正确渲染（预览内容不受系统深浅色影响，以模板配色为准）。

### 3.6 导出规格（P0/P1）
| 项 | 规格 | 优先级 |
|---|---|---|
| 公众号首图 | 900×383 px（2.35:1）PNG | P0 |
| 高清 2x | 1800×766 px | P1 |

> 1:1 次图本期不做（2026-09-16 已确认），见 §3.8 远期规划。

- 导出方式：**保存到相册** + **分享**（复用现有 ShareImageUtil），保存成功 Toast 提示路径。

### 3.7 制作历史（P1）
- 最近 20 条导出记录（缩略图 + 模板名 + 时间），可重新打开编辑；
- 与 GIF 历史同构，存储于应用沙箱。

### 3.8 远期规划（P2）
- 更多规格（1:1 次图、小红书 3:4、视频号 16:9）；自定义配色取色器；节气/节日模板包自动上新；AI 文案润色。

| E2 纹理质感 | 内置 3 张免版权纹理（纸纹/布纹/石纹）为底 | 霞鹜文楷 | 情感、美文 |

### 4.6 旗舰模板 B5「田字格字卡」详细规格（源自参考需求，P0）

**视觉规格（默认配色）**：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 画布 | 900×383 px | 2.35:1 |
| 背景色 | `#2E6FD6` 纯蓝 | 纯色，无渐变/纹理/装饰 |
| 拼音 | 顶部居中，基线 y≈90，字号 48px | 黑色，带音调字符 |
| 田字格 | 一行 5 格，水平等距、左右对称居中 | 红色 `#D8231A`，外框 3px，十字虚线 1px |
| 格子尺寸 | 130×130，间距 20，顶部 y≈150 | 格数随生字数 1-8 自适应，按等距公式缩放 |
| 格内文字 | 一字一格，水平+垂直居中 | 楷体（霞鹜文楷），黑色，字号约格宽 70% |

**自适应公式**：格边长 s 与间距 g 随字数 n 动态计算（n=5 时为上表默认值），总宽 = n×s + (n-1)×g，左右边距 = (900 − 总宽) / 2，保证任意字数均精确居中。

**槽位组合**：启用「生字（1-8 字）+ 拼音」两个槽位，**拼音由生字自动注音生成**（输入生字即实时更新，可手动修改锁定），其余槽位（署名/日期/印章/副标题）在本模板中禁用。

**硬性约束（纯净模式）**：
- ❌ 无 Logo、无二维码、无署名、无日期、无印章；
- ❌ 无背景装饰、无渐变、无阴影、无边框圆角；
- ✅ 画面只保留：**蓝色背景 + 顶部拼音 + 红色田字格 + 楷体黑字**。

**配色方案（4 套）**：蓝底红格黑字（默认）、米白底红格黑字、墨绿底米格红字、暗红底米格黑字。

## 5. 交互与 UI 需求

- 页面导航：工具页 → 首图制作页（NavDestination，标题「首图制作」）；
- 预览区点击槽位 → 滚动定位到对应输入项（P1，P0 可先做 Tab 手动切换）；
- 「换一句」按钮点击有轻微加载反馈（内容库为本地 JSON，应 <100ms）；
- 导出中显示进度条，完成后 Toast「已保存到相册」+「分享」按钮；
- 空输入校验：主标题为空时导出按钮置灰；
- 文字溢出策略：主标题按字数自动降字号（3 档），仍溢出则预览区提示「建议精简文案」。

## 6. 非功能需求

- **性能**：模板切换 <200ms 完成重绘；导出 900×383 ≤2s；页面冷启动增量 <300KB 代码体积；
- **离线**：全功能离线可用（内容库、字体均为本地资产）；
- **权限**：P0 零新增权限；E1 相册底图（P1）需读相册权限，按需弹窗；
- **合规**：内置字体均为开源可商用（OFL/站酷免费商用授权）；纹理图片需确认免版权后方可内置。

## 7. 技术方案概要

- **复用 md2png 基建**：模板注册表（TemplateInfo 模式）、组件渲染→PixelMap→保存相册/分享管线；
- **模板数据结构**：`CoverTemplate = { id, series, slots[], palettes[], defaultFont, layoutBuilder }`，布局用 ArkUI 组件实现，导出用组件截图；
- **内容联动**：复用诗词/成语/歇后语的本地 JSON 与随机推荐工具类；
- **自动注音**：引入 ohpm 三方库 `pinyin-pro`（MIT、零依赖、约 0.9MB 词典体积），`pinyin(text, { toneType: 'symbol' })` 输出带调拼音；M2 首日先做 ArkTS 兼容性验证（导入/多音字/性能），异常则降级为手动输入；
- **田字格绘制**：ArkUI 组合绘制（外框边线 + 中线虚线），格子数量/尺寸按 §4.6 等距居中公式自适应；
- **新增文件预估**：`core/cover/CoverTemplates.ets`（模板定义）、`core/cover/CoverContentUtil.ets`（内容推荐）、`pages/CoverMakerPage.ets`（页面），约 1500-2000 行。

## 8. 测试策略（TDD）

- 单元测试：模板注册完整性（15 模板×槽位×配色数量校验）、内容推荐不重复、字号自动缩放、日期自动填充；
- UI 测试：选模板→填字→导出全链路、深色模式、空标题置灰；
- 验收基准见 §9。

## 9. 验收标准

1. 工具页可见「首图制作」入口，进入页面无卡顿；
2. 15 个模板全部可选、可渲染、可导出；每个模板至少 4 套配色；
3. 导出图片尺寸精确为 900×383，PNG 格式，可保存相册、可分享；
4. 文化系模板「换一句」连续点击 10 次内容不重复；
5. 主标题 20 字情况下无文字溢出截断；
6. 深色模式下编辑界面无不可见文字；
7. B5 田字格字卡：拼音由生字**自动生成**且正确——「学而时习之」→ `xué ér shí xí zhī`（多音字消歧正确、音调符号正确显示）；手动修改拼音后导出以修改值为准；格子水平等距、左右对称居中；一字一格、居中对齐；导出画面无任何多余元素（无署名/日期/装饰）；
8. 导出耗时 ≤2s（模拟器实测）。

## 10. 边界与已知限制

- 微信若调整封面规格，需同步更新导出尺寸（模板代码与规格常量解耦，便于调整）；
- 竖排文字（B1）依赖 ArkUI Text 竖排能力，若 API 19 不支持则 B1 降级为横排（P0 兜底方案已定）；
- E1 相册底图依赖用户照片质量，蒙层不透明度固定 40%，不提供调节（保持简单）；
- 拼音自动生成依赖 pinyin-pro 词典，极冷僻多音字（如地名用字）可能注音有误，用户可手动修改拼音覆盖（应用不拦截）；
- pinyin-pro 为纯 JS 库，若 ArkTS 严格模式导入异常，兜底方案为内置本地拼音表（覆盖 3500 常用字）或降级手动输入。
