### 2.3 调试效率摩擦（工程侧，→ P1/C）

1. **toast 不可 a11y 采集**：渲染于 ARK_APP_SUBWINDOW 子窗口，主窗口 dumpLayout 不可见——协议=定时截图+像素 bbox（toast 几何稳定可复用）。
2. **uitest 协议坑**：dumpLayout 输出 JSON 非标准 XML；丢弃 3D 旋转容器下部节点（T8 PHOSPHOR 等，渲染正常仅采集缺失）；窗口号应用重启即变须 hidumper 重查；`uinput -T -M` 无效组合静默失败（正确 `-T -m`）；`-m` 滑动起终点对热区有幻影点击；**文本清空不可靠**（keyEvent BackSpace 不生效、inputText 为追加式——1.4.8 标点修复 E2E 实测旧文本残留，靠 maxLength 与分词容错兜住）。
3. **aa test 全套模拟器不可行**：SudokuOcr 管线用例逐个 30s 超时，全套 128 用例 >7min；协议=class 过滤定向 + 真机全套。
4. **构建目录互斥清理**：product 切换清掉 entry/build 下另一 product 产物（06:15 release hap 被 07:21 debug 构建清空）；app 级产物在 build/outputs/ 不受影响。发布烟测后勿急切 debug 构建。
5. **hvigor daemon 常驻**：hvigor-java-daemon.jar 长驻 java 进程非构建卡死，误杀拖慢后续构建。
6. **编码/路径三坑**：hilog 重定向 UTF-16 间隔字符（grep -a + strip \x00）；prefs 实际落盘 `haps/entry/preferences/`（顶层 preferences/ 为空目录误导）；PS GBK 控制台不能 print 中文，py 结果写 utf-8 文件再读；python 不在 PATH 用 `py -3`。
7. **bm dump 解析坑**：JSON 含 metaData/metadata 重复键，PS 5.1 ConvertFrom-Json 报错（正则提取绕开）；versionCode 首个匹配可能命中 appQuickFix 的 0（全匹配去重）。
8. **模拟器冷启动 BMS 未就绪**：bm install 报 9568391「bundle manager service is died」，就绪后重试即可（PaperVintage 批沉淀）。

## 3. 方案设计

### 3.1 P0-A 模板配置丰富

- **A1 槽位铺开（首批 3 模板，M1 已按摸底校正实现）**：复用 1.4.8 M1 CopyPosterSlotDef 框架——T5 左右软键槽（softLeft/softRight，maxLen 4×2，默认回退 $r poster_soft_left/right）、T8 屏下标语槽（screenSlogan，maxLen 24，回退 DOT MATRIX TEXT SYSTEM）、T10 表头标题槽（boardTitle，maxLen 16，回退 QUOTE BOARD，渲染 boardTitle · tag）。框架微扩：Template 增 `extraSlots`（附加语义——渲染于主文案之外，区别 T18 customSlots 替换语义）+ Content 增 softLeft/softRight/screenSlogan/boardTitle 四字段；TextEditor 在署名/标签后渲染 extraSlots 输入组。A/B 零变化协议护航（模板 defaults 不含新键、Content 默认空、渲染层空值回退现丝印，旧历史 JSON 兼容）。
- **A2 模板收藏与最近**：模板缩略图右上角 star 角标（点击切换，prefs set 存储）；「最近使用」= 保存/导出成功时记录模板 id（有序去重 top 5），模板面板顶部「最近」分组置顶；收藏模板在分类内置前。
- **A3 配色自定义**（候选，§8-1 裁剪）：配色区尾部「+ 自定义」→ 主色取色板（预设 12 色 + HEX 输入），prefs per-template 存储；渲染层 pal() 加 override（预览=导出同链验证）。
- **A4 字体扩充 / A5 纹理开关**（候选，§8-1 裁剪）：A4 五字体映射推广到全部文字模板；A5 带纹理模板样式页签加「纹理」开关（默认开）。

### 3.2 P0-B 操作审美体验

- **B1 设置收敛**：关于页升级「设置与关于」——打卡提醒开关自 AboutPage 原位重组入「提醒设置」分组，复习提醒开关自 ReviewPage 迁入（ReviewPage 保留开关位置不变仅语义提示指向设置页，避免老用户找不到，§8-3 裁定形态）；prefs key 不变（checkin_reminder_on / review_reminder_on 沿用），迁移仅 UI 位置。
- **B2 提醒直达（含降级）**：调研代理提醒通知点击路由限制（系统代理提醒不带 wantAgent）——降级方案：应用内「今日复习」到期提示条（首页顶部，点击直达 ReviewPage），通知拉起时若当日有复习任务自动展示。
- **B3 首页直达今日复习**：复习到期日首页卡片角标「今日复习 N 条」直跳 ReviewPage（复用现有到期计算）。
- **B4 toast 统一**：全应用 toast 调用点盘点；统一样式（位置上移至操作区上方、对比度审计、可选图标）；协议沿用像素 bbox 验证。
- **B5 比例切换锚定**：切 3:4/9:16 时预览保持顶部锚定（Scroll 滚动位置补偿），消除 300px 跳动。
- **B6 分类条防误触**：分类 chip 行 pan 与 click 分离（滑动阈值判定），横滑不再漂移选中态。
- **B7 深色模式抽查**：节后真机统一回归时一并（1.2.1 验收遗留）。

### 3.3 P1-C 工程侧收口

- **C1 测试债**：coverTest tc2 / charCardTest tc2 资源断言修复（断言语义改为资源解析比对或「非空资源」）；SudokuOcr 模拟器协议文档化（class 过滤用法写入测试说明，防再踩 7min 超时）。
- **C2 调试脚本沉淀**：scripts/emudit.py——dumpLayout JSON 节点检索（text/bounds/key 查询 + 中心点计算 + 像素采样），把本版调试期临时 py 脚本（find_entry/dump_cc/punct_px 系列）工具化；README 级使用说明。
