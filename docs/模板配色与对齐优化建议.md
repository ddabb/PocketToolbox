# 文案海报模板配色与对齐优化建议

- 日期：2026-11-05
- 范围：文案海报 21 个模板（T1-T21），含各模板配色与对齐逻辑
- 状态：**已执行完毕（2026-11-05），待真机/模拟器截图抽查**
- 对比度依据：WCAG 2.x 相对亮度对比度；大字（≥24px 粗体）门槛 3:1，普通字 4.5:1

## 一、结论速览

| 级别 | 模板 | 问题 | 建议方向 |
|---|---|---|---|
| P0 | T4 大字冲击 · vivid_yellow | 亮饱和黄底黑粗体发糊（晕光效应，用户反馈） | 降饱和 / 加深字色 / 减弱装饰圆 |
| P0 | T16 节气（4/5 配色） | 节气名文字色与印章底色相近，几乎不可读 | 节气名改固定浅色 |
| P1 | T1 暖调标签卡 · ink_night | 标签白字压琥珀底约 2.2:1 | grid 改深琥珀 |
| P1 | T21 层叠色块 · cobalt/lilac | 正文压前景色块 2.9~3.1:1 临界 | 前景块提亮 |
| P1 | T10 翻牌 | 头部合并文本无省略号，长文案硬裁切 | 补 textOverflow |
| P2 | T6 CRT · paper_white | 底部丝印约 2.8:1 | 丝印色提亮 |

## 二、对齐逻辑总览

现状分三个家族，均符合各自载体语义，**建议全部保留**：

1. **引用居中族**（T1/T2/T3/T4/T7/T11/T14/T15/T17/T19/T21）
   正文走 BodyBlock（PosterTypeset 核心字号）+ TextAlign.Center，署名随正文居中。引用式海报的标准版式。
2. **载体左对齐族**
   - T5 LCD / T6 CRT / T8 掌机：正文左对齐，符合设备屏幕、终端提示符（`C:\>`）语义；T5 软键 SpaceBetween。
   - T9 车票：正文左对齐 + 弯引号包裹，票据语义。
   - T12 聊天：正文气泡左对齐、署名气泡右对齐，聊天 UI 惯例。
   - T13 黑胶：曲目行（编号+文字+时长）底部对齐左排，曲目列表惯例。
3. **传统竖排族**
   - T16 节气：正文竖排从右起，节气名居左、署名右下，传统节气版式。
   - T18 红包：横批居中、对联两列、署名右下竖排。
   - T20 竖排引用：右起竖排；padding 左 80 / 右 140 不对称，为补偿右侧竖线（x≈842），光学中心左移约 31px（900px 设计稿制），合理。

可选实验项（默认不做）：T11 报纸正文目前居中，报纸更常见左对齐/两端对齐；如改需 BodyBlock/PosterTypeset 支持 start 对齐的测量分支，成本较高，收益存疑，建议保持现状。

## 三、逐模板分析与建议

### T1 暖调标签卡 — P1
现状：TagPill 文字硬编码 #FFFFFF，底色取 grid。
问题：ink_night 配色 grid=#F59E0B（琥珀），白字压琥珀约 2.2:1，小号标签发灰难读；其余 4 配色（#D8231A/#B45309/#2F6B4F/#E11D48）均达标。
建议：ink_night 的 grid 调为深琥珀 #B45309（约 4.6:1），只改配色表，不动渲染代码。
对齐：居中族，无问题。

### T2 纯色简约 — 达标
4 配色均 ≥4.5:1；true_red 米金点缀、graphite 琥珀点缀在深底上清晰。无改动。

### T3 文艺手写 — 达标
墨色系刻意低饱和但均 ≥7:1（如 #3B2F24 压 #FBF7EF），文学风格成立。无改动。

### T4 大字冲击 — P0（用户反馈）+ P3
现状（vivid_yellow）：bg #FFD100、title/accent #1F1F1F、sub #4A4A4A（tag 用）、装饰圆 block #E8BC00 @ opacity 0.35。
问题分析：
1. "黄底黑粗体发糊"的根因是**晕光（halation）**：#FFD100 亮度约 0.67 且高饱和，暗色粗笔画边缘产生眩光，配合黄油体的粗密笔画，观感发糊。对比度数值 11.3:1 本身达标，问题在色彩观感而非对比度。
2. tag 用中灰 #4A4A4A 压黄底，小字号下显脏。
3. 装饰圆 #E8BC00@0.35 在黄底上叠出中黄带且处于正文后方，进一步削弱文字边缘清晰度。
建议（保留"黄底黑字"冲击感，减晕光）：
- bg：#FFD100 → #FFE066（降饱和，晕光显著减弱）
- title：#1F1F1F → #141414（笔画更实）
- tag sub：#4A4A4A → #141414（与正文同色，去掉灰）
- 装饰圆 opacity 0.35 → 0.2
- 可选：新增第 6 配色"墨夜黄"（bg #141414、title #FFD100、accent #FFD100）——黑底黄字反向，彻底规避晕光。是否新增由你定。
P3（cherry_pink）：title #FDF2F8 压 #DB2777 约 4.2:1，达标但淡粉偏灰白，可选改 #FFFFFF（约 5.3:1）。
对齐：居中族，无问题。

### T5 LCD — P2（仅 warm_desk）
问题：warm_desk 为亮台面（bg #E5DFD3），但 LcdVignette 统一用 '#CC000000' 重黑晕影，亮底上四角发脏；night_glow 深底无此问题。
建议：亮台面配色晕影减为 '#663A3226' 棕色轻晕（或 vignette 色随配色走）。
对齐：正文左对齐 + 软键 SpaceBetween，保留。

### T6 CRT — P2（仅 paper_white）
问题：底部丝印文字硬编码 #8D8471，压机壳 #3A3D42 约 2.8:1，16px 小字偏弱。
建议：丝印色改 #B8B2A4（约 4.5:1），仅一处常量。
对齐：终端左对齐保留。

### T7 霓虹 — 达标
深底辉光管设计，管色（block）与辉光（accent）在深底上均清晰。无改动。

### T8 掌机 — 达标
墨绿 LCD 固定配色（#1F2D16 压 #9BB069 约 7:1），外壳配色独立于屏字。无改动。

### T9 复古车票 — 达标
纸/墨对比 ≥9:1，章戳 accent 压深底清晰。无改动。票据左对齐保留。

### T10 翻牌 — P1（小改动）
问题：FlapHeader 将标题+副题合并单行 Text（'·' 分隔）maxLines(1) 未设 textOverflow，长文案被硬裁切。
建议：补 `.textOverflow({ overflow: TextOverflow.Ellipsis })`。
对齐：翻牌行居中、头部 SpaceBetween，保留。

### T11 报纸 — 达标
深浅两版纸墨对比 ≥9:1。正文居中见对齐总览"可选实验项"，默认保留。

### T12 聊天 — 达标
- wechat_green：#191919 压 #95EC69 约 10:1
- midnight_chat：#E8EAF0 压 #2E5C4A 约 7:1
- 其余 ≥4.5:1
对齐：正文左、署名右，聊天惯例保留。

### T13 黑胶 — 达标
- retro_orange 标签：#241708 压 #E8833A 约 6:1
- midnight_vinyl：约 12:1
对齐：曲目底部对齐保留。

### T14 电影 — 达标
两款字幕底条与文字对比 ≥7:1。无改动。

### T15 公告栏 — P2（仅 midnight_chalk）
问题：midnight_chalk 深蓝黑板（bg #1E2430）下开启木纹时，棕色纹理贴图叠深底发浑，与黑板质感冲突；classic_cork 棕底无问题。
建议：深色配色下木纹透明度降至约 0.35，或叠加 bg 色半透明遮罩统一色调。
对齐：卡片文字居中、位置固定，保留。

### T16 节气 — P0（可读性 bug）

| rice_seal | #3B4A3F | #B03A2E | 约 1.6:1 ✗ |
| celadon_term | #2F6B4F | #C0392B | 约 1.2:1 ✗ |
| rouge_term | #8C3A4E | #B03A5B | 约 1.5:1 ✗ |
| xiang_paper | #6E5230 | #8C6A3F | 约 1.5:1 ✗ |

建议：节气名文字改固定浅色 #F6EFDE（与"节气"小印章文字一致），一处渲染代码改动，全部配色立即达标（红/棕底压浅字 ≥4.5:1）。
对齐：竖排右起、署名右下，传统版式保留。

### T17 节日 — 达标
深底金字 / 浅底红字均 ≥7:1。无改动。

### T18 红包 — 达标
红金、墨绿金对比 ≥8:1。无改动。

### T19 撕纸便签 — 达标
纸面 #F4EFE3 压墨 #2B241C 约 13:1；桌面色仅作背景。无改动。

### T20 竖排引用 — 达标
和纸底墨字 ≥9:1。不对称 padding 补偿右竖线，保留（见对齐总览）。

### T21 层叠色块 — P1（cobalt/lilac 临界）
现状：正文色 pal().title 压前景块 accent（旋转 -2.4° 主块）：

| 配色 | title | accent（前景块） | 对比度 |
|---|---|---|---|
| cobalt_stack | #1A2233 | #2E5FD6 | 约 2.9:1 ✗ |
| lilac_stack | #231A33 | #7C4DD6 | 约 3.1:1 临界 |
| mint_stack | #132A1E | #12A06A | 约 4.9:1 ✓ |
| sunset_stack | #2B1D14 | #F2622E | 约 5.5:1 ✓ |

建议：cobalt accent → #4479E8（约 3.6:1）、lilac accent → #8E63E0（约 3.6:1），back block 同步微调维持层次；仅改配色表。
对齐：居中族，无问题。
