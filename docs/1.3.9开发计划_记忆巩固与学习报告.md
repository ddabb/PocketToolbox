## A1 默写练习（主功能）
- **玩法**：逐句挖空补全——整诗按标点切句，每句随机遮 20~30% 的字（句长≥4 挖 ceil(len×0.25)、上限 4；短句挖 1），**挖空字位上方仍显示拼音（看拼音写汉字）**，复用 `CoverContentUtil.autoPinyin/syllables` 引擎与 PinyinText 的指针对齐模式
- **输入**：句下方单 TextInput，过滤非汉字、长度=挖空数时提交可点；判定后字格变绿/红，红格内显示正确字
- **流程**：三态 loading/playing/finished；每句「提交 → 重练本句 / 下一句」；结束页显示完成度与完美句数，可「再练一次」重新随机
- **防刷**：每句仅首次判定计入统计（Set 记录已计句子索引），重练不重复计数
- **数据来源**：PoemContentPage「默写」chip 传入当前 PoemItem；DailyChallengePage 入口卡不传参 → 页面用「今日诗词」seed 算法（复用 DailyPoemWidgetUtil 同款 `Math.sin(seed)*10000` 随机，seed=YYYYMMDD）
- **统计与成就**：UserStats 新增 `dictationTotal`（累计判定句）/ `dictationPerfect`（累计完美句）+ `recordDictationSentence(context, perfect)`；成就 3 枚：dictation_first（落笔成章）/ dictation_perfect_10（字字珠玑，statKey=dictationPerfect）/ dictation_total_30（熟读成诵，statKey=dictationTotal）
- **页面**：`pages/DictationPage.ets` + `common/utils/DictationUtil.ets`（切句/挖空/判定纯逻辑）；路由注册 router_map + Index PageMap；范式A 720 约束列
