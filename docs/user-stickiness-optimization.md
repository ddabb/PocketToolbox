# 解语珠玑 — 单机应用用户黏性优化建议

## 一、应用现状分析

**核心功能**：诗词查询、成语查询（顺查/逆查/接龙）、歇后语查询、单位换算、进制转换、时区转换、文字转图片、朗读清单（TTS）

**已有黏性机制**：
- 每日一诗 / 每日成语 / 每日歇后语（基于日期种子，每日固定内容）
- 收藏体系（上限 200 条，按类型分组）
- 朗读清单（自建播放列表 + TTS 顺序播放）
- 搜索历史（诗词查询保留最近 5 条）
- 浏览次数统计

**主要短板**：功能间关联弱，缺乏长期激励，用户行为数据未充分利用，社交/分享链路未闭环。

## 二、优化建议

### 1. 学习打卡与连续签到

| 维度 | 说明 |
|------|------|
| 目标 | 建立每日回访习惯 |
| 方案 | 每日签到 + 连续签到天数记录，7/14/30 天里程碑徽章；签到时自动推送当日诗词/成语，降低操作成本 |
| 数据存储 | preferences 存 `last_check_in_date`、`check_in_streak`、`total_check_in_days` |
| UI 入口 | 首页顶部增加签到入口，"我的"页增加签到日历卡片 |

### 2. 成就与徽章体系

| 维度 | 说明 |
|------|------|
| 目标 | 长期目标感，鼓励深度使用 |
| 方案 | 多维度成就：收藏达人（收藏数里程碑）、诗词博览（浏览诗人数量）、成语接龙高手（接龙次数/最长链）、每日坚持（连续签到）、工具达人（使用不同工具类型数）。达成后解锁徽章，"我的"页展示徽章墙 |
| 数据存储 | preferences 存各维度进度值，JSON 结构 |
| 展示 | "我的"页新增"我的成就"入口，独立成就页展示已解锁/未解锁徽章 |

### 3. 每日挑战与趣味互动

| 维度 | 说明 |
|------|------|
| 目标 | 增加每日停留时长与趣味性 |
| 方案 | （1）诗词填空：给出诗句缺字，用户选择填写；（2）成语接龙挑战：系统出题，限时连续接龙；（3）歇后语猜谜：只显示前半句，点击揭晓答案。每日一套题，基于日期种子生成 |
| 数据存储 | preferences 存 `daily_challenge_date`、`daily_challenge_score`、`challenge_history` |
| 激励 | 挑战得分累计进成就体系 |

### 4. 个性化推荐与智能刷新

| 维度 | 说明 |
|------|------|
| 目标 | 让"每日推荐"更贴合用户兴趣 |
| 方案 | 记录用户浏览/收藏的朝代、诗人偏好，每日推荐优先从偏好池选取；当前刷新按钮完全随机，改为"换一换"时加权偏好，同时保留随机发现能力 |
| 数据存储 | preferences 存 `pref_dynasties`、`pref_poets`（浏览/收藏频率 Top5） |
| 实现 | `loadDailyPoem` 中根据偏好权重调整 seed 选择范围 |

### 5. 收藏体系增强

| 维度 | 说明 |
|------|------|
| 目标 | 让收藏从"存了就忘"变为"持续回看" |
| 方案 | （1）收藏分组/标签：自定义标签（如"考试必背"、"孩子学习"），支持按标签筛选；（2）收藏复习提醒：对诗词类收藏，随机在首页"温故知新"卡片中推送已收藏内容；（3）收藏笔记：每条收藏支持追加个人笔记字段 |
| 数据存储 | FavoriteItem 增加 `tags: string[]`、`note: string` 字段 |
| UI | 收藏页增加标签筛选栏、笔记编辑入口；首页增加"温故知新"卡片 |

### 6. 朗读清单体验优化

| 维度 | 说明 |
|------|------|
| 目标 | 提升朗读场景的粘性和回访 |
| 方案 | （1）朗读进度记忆：记录每个清单的播放位置，下次打开自动续播；（2）快速创建：从详情页一键"朗读这首"自动加入默认清单，无需先建清单再添加；（3）朗读历史：记录已朗读完成的内容，形成"已读"列表；（4）朗读统计：累计朗读时长、朗读篇数，计入成就体系 |
| 数据存储 | ReadingList 增加 `lastPlayedIndex`、`lastPlayedTime`；新增 `reading_stats` 存储 |

### 7. 搜索与发现优化

| 维度 | 说明 |
|------|------|
| 目标 | 降低查找成本，增加探索乐趣 |
| 方案 | （1）全局搜索：首页顶部搜索框，统一搜索诗词/成语/歇后语，跨模块结果展示；（2）相关推荐：诗词详情页底部推荐同朝代/同主题诗词，成语详情页推荐同首字/相关成语；（3）热搜/随机发现：首页增加"随便看看"入口，随机推送内容 |
| 数据存储 | 搜索历史扩展为全局搜索历史，上限增至 20 条 |

### 8. 分享与社交裂变（单机友好）

| 维度 | 说明 |
|------|------|
| 目标 | 在无后端情况下实现分享传播 |
| 方案 | （1）诗词/成语卡片分享：生成精美图片卡片（已有 ShareImageCard 组件），支持保存到相册和系统分享；（2）成就海报：达成里程碑时生成成就分享图；（3）每日推荐分享：每日诗词卡片带二维码/应用名水印 |
| 技术点 | 复用现有 Md2Png 的 Canvas 渲染能力，扩展为模板化卡片生成器 |

### 9. 桌面小组件（Form Extension）

| 维度 | 说明 |
|------|------|
| 目标 | 桌面常驻，提升每日触达 |
| 方案 | 提供每日诗词/成语桌面卡片小组件（1x2 或 2x2），定时刷新，点击跳转应用对应详情页 |
| 技术点 | HarmonyOS Form Extension，定时更新（`updateEnabled` + `updateDuration`），数据从 preferences 读取 |

### 10. 数据统计仪表盘

| 维度 | 说明 |
|------|------|
| 目标 | 让用户感知自己的使用轨迹，增强归属感 |
| 方案 | "我的"页扩展统计：累计使用天数、本周/本月活跃天数、最常浏览的朝代/诗人、收藏趋势图（最近 7 天新增）、朗读时长统计 |
| 数据存储 | preferences 存 `daily_active_dates`（近 30 天 bitmap）、各维度累计值 |
| UI | "我的"页统计区从 4 格扩展为可展开的统计面板 |

## 三、优先级排序

| 优先级 | 建议 | 预期收益 | 实现难度 |
|--------|------|----------|----------|
| P0 | 每日挑战与趣味互动 | 高 — 提升停留时长 | 中 |
| P0 | 学习打卡与连续签到 | 高 — 建立回访习惯 | 低 |
| P1 | 成就与徽章体系 | 高 — 长期目标感 | 中 |
| P1 | 个性化推荐与智能刷新 | 中 — 提升推荐质量 | 低 |
| P1 | 收藏体系增强 | 中 — 提升回看率 | 中 |
| P2 | 朗读清单体验优化 | 中 — 深化核心场景 | 中 |
| P2 | 搜索与发现优化 | 中 — 降低使用门槛 | 中 |
| P2 | 分享与社交裂变 | 中 — 扩大传播 | 低 |
| P3 | 桌面小组件 | 高 — 桌面触达 | 高 |
| P3 | 数据统计仪表盘 | 低 — 增强归属感 | 中 |

## 四、数据存储策略

所有建议均基于单机 `preferences` 实现，无需后端：

- **偏好键命名规范**：`stickiness_` 前缀，如 `stickiness_check_in_streak`
- **数据量控制**：单个 key 对应的 JSON 不超过 4KB（preferences 限制）
- **缓存策略**：复用现有 `FavoritesUtil` 的缓存模式（内存缓存 + invalidateCache）
- **备份兼容**：现有 backup extension 已覆盖 preferences，新增数据自动纳入备份

## 五、关键指标追踪建议

虽然单机应用无远程埋点，可在本地记录以下指标供用户自查：

1. **DAU 代理**：`daily_active_dates` 记录近 90 天活跃日期
2. **功能渗透率**：各功能页进入次数（`visit_count_poetry`、`visit_count_idiom` 等）
3. **收藏转化率**：浏览量 vs 收藏量比值
4. **朗读完成率**：朗读清单播放完成次数 / 总播放次数
5. **挑战参与率**：每日挑战打开次数 / 签到次数
