# 付费应用改造方案（口袋工具箱 · 整包付费）

| 版本 | 日期 | 说明 |
| --- | --- | --- |
| v1.0 | 2026-09-21 | 按层面梳理免费转付费所需的全部调整项；执行排期见《变现开发计划.md》（v2.0，决策：个人开发者 · 整包付费下载） |

> 本文回答"**要在哪些层面做调整**"；具体阶段排期、工作量与风险对策见《变现开发计划.md》，两文配合使用。

## 0. 模式结论（背景）

个人开发者无法接入鲸鸿动能广告、也不在本期做 IAP，已选定**整包付费下载**（AppGallery `Payment type = Paid`，国内 ¥6 / 海外 $0.99）。该模式的特点是：**收费发生在分发层（商店），不在应用内**，因此改造重心在"管理侧 + 打包 + 合规 + 运营"，应用代码本身改动极小。

---

## 1. 开发者账号与商户层（前置硬条件）

| 调整项 | 现状 | 目标 |
| --- | --- | --- |
| 实名认证 | 个人主体（已完成） | 无需变更 |
| 商户服务 | 未开通 | 管理中心开通：签署协议、绑定结算银行卡、填写税务信息 |
| 结算 | 无 | 期望次月出账、按周期打款；华为抽成 15%，¥6 到手 ≈ ¥5.1 |
| 资质 | — | 无需特殊资质（工具类非敏感行业） |

## 2. AGC 管理配置层

1. **定价与分发**：`Payment type = Paid`；基础价 ¥6（含税）→ 币种 CNY → 选择目标国家/地区，由系统按汇率+税率换算本地价（海外 $0.99 主推）。
2. **价格维护**：华为每日更新汇率但**不自动刷新已保存价格**，长期运营需定期手动更新各国价格。
3. **质量分门槛**：质量分 **≥ 4.0** 才允许设付费。当前评分与崩溃情况须先修复到位（详见 §8 测试层）。
4. **应用内容**：隐私政策 URL 必须可公开访问（需先落实托管位置），并更新支付相关披露（见 §5）。

## 3. 构建与打包层

| 检查项 | 项目现状 | 要求 / 动作 |
| --- | --- | --- |
| 模型 | Stage 模型（ArkTS） | ✅ 满足（FA 模型不支持加密，无法付费） |
| API 版本 | compatibleSdkVersion 5.1.0(18) | ✅ > 10 满足 |
| 安装包加密 | 未加密 | 上传 AGC 时设置 **require encryption**；旧版本若已 `Released` 且未加密，须**新建版本、重打加密包、发布后再设付费** |
| 签名 | build-profile 已有 release 签名配置（D:/keystore） | ✅ 使用 release 证书构建上架包；确认证书未过期 |
| 版本号 | 1.2.1（versionCode 1000009 / buildVersion 3） | 上架付费版时递增 versionCode；更新日志中说明收费切换 |
| 构建命令 | — | 用 `product = release` + `build_mode = release` 出正式包，本地安装自测后再上传 |
| 发布类型 | — | 须为测试 / 分阶段 / 全量发布（不能停留草稿） |

## 4. 应用代码层（改动极小，但有几点建议）

整包付费 = 安装即付费用户，**无需**支付 SDK、权益判断（`EntitlementUtil`）、订单校验等组件。建议的少量调整：

1. **关于页（AboutPage）**：补充"付费说明"（价格、买断性质、老用户免费升级说明）；放隐私政策 URL 入口，方便审核与用户查阅。
2. **更新日志/公告**：版本更新说明中明确"自 vX.Y.Z 起转为付费应用，已安装用户可免费升级"。
3. **清理开发态遗留**：确认无调试开关、测试入口、控制台敏感日志输出。
4. **启动性能**：付费用户对品质期望更高，保持冷启动达标（诗词/成语/歇后语数据加载已做懒加载，回归确认即可）。
5. **预留演进空间**（本期不实施）：若未来转「免费 + IAP 功能买断」，需要新增 IAP Kit（`@kit.IapKit`）商品配置、权益管理模块与服务端订单验签；商品卖点须为"功能解锁"而非"去广告"。本期**不做**。

## 5. 隐私与法务层

1. **隐私政策更新**：
   - 披露：支付/订单数据处理方为**华为**（AppGallery 付费下载，开发者不收集支付信息）；
   - 保持现有权限说明与实际用途一致（INTERNET / VIBRATE / PUBLISH_AGENT_REMINDER / KEEP_BACKGROUND_RUNNING，module.json5 中均已声明 reason）。
2. **权限最小化复核**：4 个权限均为既有功能（网络、振动反馈、提醒、后台朗读）所需，无冗余；付费审核更严，保持现状即可，不新增权限。
3. **退款政策**：AppGallery 支持用户申请退款；商店侧默认流程即可，无需自建；更新日志/说明中避免"不支持退款"类表述。
4. **未成年人**：非实名/年龄敏感应用，无特殊调整。

## 6. 内容与素材合规层（收费后风险放大，需自查）

免费时代"素材来源"少有人追究；**收费后属于商用，须逐项确认授权**：

| 素材 | 用途 | 状态与动作 |
| --- | --- | --- |
| 开源字体（得意黑、霞鹜文楷、马善政、站酷系、思源系、寒蝉系、仓耳系等 15 款） | 词云生成、生字卡、首图制作（Md2PngTemplates.FONT_*） | 逐款确认许可证（OFL/授权协议）允许**商业使用**并保留版权声明；站酷快乐体等有独立授权条款，需单独核对；如个别字体仅限个人使用，需替换 |
| 诗词/成语/歇后语文本 | 查询、朗读清单、每日推荐 | 公版内容，可商用；个别近现代诗人作品（如近现代分类）需确认已进入公版或取得授权 |
| 模板/图标/示例素材 | 首图模板、桌面卡片图标 | 确认为自制或可商用素材 |
| **建议** | — | 在关于页或首图/词云导出页保留字体版权声明（OFL 本身要求） |

## 7. 商店展示与存量过渡层

1. **ASO 与素材**：标题/关键词/截图/描述围绕"买断制无广告全功能"重写；价格出现在商店页，截图与描述避免误导。
2. **存量用户过渡**：
   - 公告"已安装用户免费升级"（更新日志 + 关于页）；
   - 使用**分阶段发布**灰度切付费，监控转化率与评分波动；
   - 准备差评应对话术（老用户误解收费时引导说明）。
3. **先免费攒分 → 后切付费**：若当前质量分不足 4.0，先发免费修复版提分，再切付费。

## 8. 测试与质量层（付费后质量门槛提高）

1. **加密包本地校验**：构建加密包后本地安装自测（当前模拟器 + 真机双通道）。
2. **购买流程验证**：用测试账号/测试机器走完整付费下载、卸载重装、退款后再安装等路径。
3. **已知问题清零**：付费用户容忍度显著降低，上线前修复 P1/P2 遗留（如 TTS 朗读在部分真机的兼容性——模拟器无 TTS 服务已确认，真机表现需回归）。
4. **崩溃率与 ANS**：重点监控付费版本崩溃率，保持 < 0.1% 水平。

## 9. 运营与财务层

1. **对账**：每月核对 AGC 结算单与银行卡到账（扣除 15% 抽成与代扣税）。
2. **数据监控**：下载转化（商店页浏览→付费下载）、评分、退款率。
3. **价格策略**：¥6 为渗透价，稳定后可评估调价（调价影响新用户，不影响已购用户）。
4. **持续收入**：接受一次性买断模型；若 ARPU 不达预期，再评估「免费 + IAP」方案（另立文档）。

## 10. 落地检查清单

- [ ] 商户服务开通（协议 + 银行卡 + 税务）
- [ ] 定价配置（¥6 基准价、CNY、目标地区、海外价确认 $0.99）
- [ ] 隐私政策 URL 托管可访问，并更新支付披露
- [ ] 15 款字体商用授权逐款确认（重点：站酷系、仓耳系独立条款）
- [ ] release 包 + 安装包加密，本地安装自测通过
- [ ] versionCode 递增、更新日志含"老用户免费升级"说明
- [ ] 关于页补充付费说明与隐私政策入口
- [ ] 质量分 ≥ 4.0（不足则先发免费修复版）
- [ ] 分阶段发布灰度，监控评分与转化
- [ ] 上线后首周每日巡检（评分/崩溃/退款）

## 11. 分层责任与依赖关系

```
账号商户层（§1） ──► AGC 配置层（§2） ──► 上架审核 ──► 存量过渡（§7）──► 运营财务（§9）
                        ▲                     ▲
        构建打包层（§3）─┘                     │
        代码层（§4）+ 法务层（§5）+ 素材合规层（§6）+ 质量层（§8）─┘（全部为提审前置）
```

关键路径：**商户开通 → 定价 → 加密包 → 审核通过**；素材合规（§6）与隐私政策（§5）是最容易被忽视的提审阻塞项，建议与商户开通并行启动。
