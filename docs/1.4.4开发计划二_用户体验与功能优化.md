## 3. 需求详述

### 3.1 P0-1：成就解锁即时反馈
| 项 | 内容 |
|---|---|
| 现状 | `checkAchievements()` 由约 10 处调用（签到/挑战/复习/默写/飞花令/导出等），解锁仅置 `item.unlocked = true` 并 bump `AchievementDataVersion`（1.4.1）；除我的页计数刷新外用户无感知，发现解锁须自行进成就页 |
| 提示形式 | **一律合并为单条**（已批准）：每次检查产生新解锁时弹一条 Toast「解锁 {N} 枚新成就」（N=1 同文案），不做逐条排队 |
| 红点 | 我的页成就入口红点：新解锁未查看计数存 preferences（防杀进程丢失），入口显示红点，进入成就页清零 |
| 时序 | 成就 Toast 与既有成功 Toast（签到/导出）冲突时延后展示，不并发覆盖 |
| 三语 | 新键 `ach_unlock_toast`（解锁 %d 枚新成就）×3 |
| 验收 | 签到/导出/默写/飞花令等首次达成即弹合并提示；红点出现→进成就页→清零；杀进程红点仍在；一次多枚仍一条；深色模式正常 |

### 3.2 P0-2：词云/文字转图片历史记录（含缩略图）
| 项 | 内容 |
|---|---|
| 现状 | 词云、Md2Png 无历史（首图/生字卡共用 `CoverHistoryStore`，文案海报复用 `poster_history`，GIF 有 `GifHistoryStore` 含产物文件）——《建议》#5 闭环仅剩两角 |
| 存储 | **参数 + 缩略图**（已批准）：词云记录文本（截断 2000 字）、形状、配色组、尺寸、时间；Md2Png 记录 markdown 源（截断 2000 字）、模板 id、时间；均另存**缩略图 PNG**（约 360px 宽，files 目录，参照 `GifHistoryStore` 文件管理范式） |
| 淘汰 | LRU 上限 20 条，淘汰时**同步删除缩略图文件**防膨胀 |
| 入口 | 两页主流程露出「最近制作」入口，点击恢复参数再编辑、重新生成导出，与既有工具范式一致 |
| 验收 | 生成→杀进程→重进→缩略图正确显示→恢复参数→再导出一致；超上限淘汰且文件删净；三语；深色模式 |

### 3.3 P0-3：剪贴板一键填入（文案海报 + 生字卡）
| 项 | 内容 |
|---|---|
| 现状 | 主文案/生字输入为高频输入，用户常从微信/备忘录复制文字后进 App，需手动聚焦粘贴；需求文档 §3.11「剪贴板智能识别」列远期 |
| 范围 | **文案海报主文案 + 生字卡文本输入**（已批准扩展，含文本模式生字输入与句子模式句子输入），机制抽共享 util 便于后续复用 |
| 方案 | 进入页面且目标输入为空时读剪贴板（pasteboard，纯文本非空即提示），输入区上方非侵入提示条「检测到剪贴板内容：{前 N 字预览}…」+「填入」按钮；点击按各页既有上限截断后填入；关闭或填入后本会话不再提示；空/非文本/读取异常一律静默 |
| 边界 | 仅提示 + 用户点击才写入，不自动上报；隐私合规实现前查证 API 24 真机剪贴板读取行为，受限场景静默降级 |
| 验收 | 复制短文本进两页均出提示条；填入正确（超长按上限截断）；复制空/图片不提示；同会话不重复；关闭后不复活 |

### 3.4 P0-4：复习卡回退池
| 项 | 内容 |
|---|---|
| 现状 | Index.ets loadReviewItem：诗词收藏为空时回退**全部收藏**（成语/歇后语混入），违背《建议》#6"回退每日诗词池" |
| 方案 | 诗词收藏 < 7 条时回退每日诗词池（复用每日诗词既有 seed 机制），保证内容新鲜度；池为空维持现状 |
| 验收 | 仅收藏 2 条成语时，首页复习卡出诗不出成语；收藏充足时行为不变 |

### 3.5 P1-5：文案海报水印开关（文字可编辑）
| 项 | 内容 |
|---|---|
| 现状 | 导出图无任何标识（需求文档 §3.11 水印选项列远期） |
| 方案 | 样式区新增「水印」开关（默认关）+ **水印文字输入框**（已批准可编辑；默认预填「@随身工具宝」类品牌文案， maxLength 12，清空则不渲染水印文字）；开启后根画布右下角渲染小字水印，随历史记录存储（watermarkOn + watermarkText 两字段，旧记录缺省兼容） |

| 验收 | 开关 × 3 比例出图右下角有小字；编辑文字生效、清空不渲染；历史往返保持；与注音开关同区不拥挤；三语 |

### 3.6 P1-6：GIF 模式卡片 emoji 清理
| 项 | 内容 |
|---|---|

## 5. 交互与 UI 需求
- 成就 Toast 不与既有成功 Toast 并发覆盖（延后展示）；
- 历史入口与既有工具「最近制作」范式一致（位置、交互、恢复行为、缩略图尺寸）；
- 剪贴板提示条为非侵入式（不遮挡预览/编辑主区，可关闭）；
- 水印开关、注音开关、尺寸 chips 同区布局不拥挤（样式区排布复核）；
- 新增 UI 文案三语 `$r` 化。

## 6. 技术方案概要
- 成就：`StickinessUtil.checkAchievements` 返回本次新解锁数；调用点统一走带反馈包装；红点计数存 preferences 并与 `AchievementDataVersion` 联动；
- 历史：词云/Md2Png 各建轻量 preferences 存储 + files 目录缩略图（参照 `GifHistoryStore` 范式，LRU 20 条，文本截断 2000 字，淘汰删文件）；
- 剪贴板：共享 util 封装「读取 + 有效性判断 + 会话标记」，两个页面接入；
- 水印：`CopyPosterModels.CopyPosterContent` 增 `watermarkOn`/`watermarkText` 字段（历史 JSON 向后兼容，缺省关/空），`CopyPosterPreview` 根层渲染；
- 版本：**AppScope/app.json5 不动**。

### 实施补充（2026-10-12 开发中记录，均在规格预留范围内）
8. **P0-3 读取路线降级**：API 12+ 程序化读剪贴板需 `READ_PASTEBOARD`（restricted 权限，工程未声明、上架不可用）→ 改 **PasteButton 安全控件**：进入页面用 `hasDataType` 免权探测出提示条，用户点击安全控件按钮临时授权 `getData` 读取并填入；提示条**不含前 N 字预览**（读取受限场景静默降级，§3.3 边界预留）；
9. **P0-3 触发条件调整**：规格「目标输入为空时」不可行（文案海报 `aboutToAppear` 预填 T1 默认文案、生字卡默认「学而时习之」，进入时输入永不为空）→ 改为**进入页面探测到剪贴板含文本即提示**，填入/关闭后本会话不再提示；
10. **P1-5 默认水印文案**：取实际应用名「@解语珠玑」（AppScope `app_name`；规格例「@随身工具宝」为泛指示意），经 `poster_watermark_default` 资源三语可改；水印两字段存 `CopyPosterContent`（随 textsJson 进历史，旧记录缺省兼容）；模板横滑缩略图（96px）经新增 `showWatermark` 参数关闭防糊点；导出走主预览快照自然携带水印；水印色取 palette `title` 50% 透明，18 模板均可读；
11. **P1-6 落地**：新增 `gif_history.svg`（时钟意象，#6366f1 与卡片色一致）；`ModeCard` 图标参数放宽为 `ResourceStr`（string 分支渲染 emoji Text、Resource 分支渲染 Image），其余三卡调用零改动；GIF 历史空态同款 🕘 emoji 一并替换，#2 收口彻底。
