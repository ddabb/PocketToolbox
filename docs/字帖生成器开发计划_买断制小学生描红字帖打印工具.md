# 字帖生成器开发计划：买断制小学生描红字帖打印工具（v1.0.0 立项）

> 立项：2026-10-19 ／ 形态：HarmonyOS 原生单 HAP 买断制应用 ／ 定价：¥6（首发限时 ¥4）
> bundleName：com.ddabb.copybook ／ vendor：lgayy ／ 网络：零网络权限（全离线）
> 一句话定位：鸿蒙原生小学生字帖生成器——描红 / 临写 / 笔顺分解 / 课标字表·古诗内容库 / A4 打印，一次买断、无广告、无订阅、无账号。

## 1. 立项背景与产品定位

### 1.1 为什么是字帖生成器
- 硬刚需高频：写好字是一二年级语文的日常作业与家长共识焦虑；"每日一页描红字帖"是幼小衔接与低年级的标配练习；打印字帖是标准介质。
- 付费人群明确：与口算题卡同一家长人群（数学+语文"作业双件套"心智，互相导流）；一本印刷字帖册 ¥15-30 且内容固定，淘宝字帖 PDF ¥1-5 需自行搜寻且质量参差。
- HarmonyOS NEXT 生态空缺：应用市场检索"字帖/描红"，缺乏原生买断应用；存量竞争为免费网页生成器与印刷字帖。
- 买断制天然匹配：字帖由本地引擎生成（按需无限生成、零内容运营），内容库为一次性内置静态资产（课标公开字表 + 公有领域古诗）——成本结构 = 一次性开发 + 内容校对 + 版本维护。
- 可行性高：核心 = 格矩阵版面引擎 + 描红/笔顺位图渲染 + 打印管线（自有 PdfComposer 内核源码移植，250 行已验证代码，口算题卡项目同款）；格线绘制与拼音标注经验直接来自工具箱生字卡实践。

### 1.2 与 PocketToolbox 的边界（买断价值独立声明）
| 维度 | PocketToolbox 生字卡 | 字帖生成器 |
| --- | --- | --- |
| 产品职能 | 识字卡片：认字（看与分享） | 习字练习册：写字（打印练习） |
| 形态 | 单张图卡（1-12 字，方卡/练习卡/首图） | 多页 A4 可打印字帖（整本，数百字） |

识字与习字是语文学习的两个阶段、两类作业：生字卡解决"认得"（flashcard），字帖解决"写好"（copybook）——生字卡不做任何打印字帖（无打印/无描红/无笔顺/无内容库），字帖生成器不做任何卡片美化；两者是"单词卡 App"与"英文书法练习册"的关系，家长都需要但用途互不替代。

## 2. 目标用户与核心场景

- 一二年级家长（主力）：每日练字作业打印；幼小衔接描红启蒙（幼儿园大班）。
- 书法启蒙场景：单字专项深练（笔顺分解 + 整页单字帖）。
- 内容练字场景：古诗字帖（练字兼背诵）。
- **P0 必须丝滑的核心场景**：内容库选"一年级字表" → 模式选"描红" → 格型田字格 → 生成 → 预览 → 导出 PDF → 打印。全程 < 10 秒、零弹窗、零广告。

## 3. 竞品与差异化

| 竞品 | 形态 | 弱点（即机会） |
| --- | --- | --- |
| 免费网页字帖生成器 | 免费 | **无笔顺数据**（普遍只做格线+描红字）、在线操作、无古诗内容库整合、无多模式一键 |
| 淘宝字帖 PDF | ¥1-5 | 内容固定、质量参差、需自行搜寻 |
| 印刷字帖册 | 实体 ¥15-30 | 内容固定做完即弃、无法按弱字定制 |
| 付费字帖 App | 少见 | 鸿蒙原生类目空白 |

差异化主张：
1. **笔顺帖**（逐笔递进分解，Make Me a Hanzi MIT 笔画数据）——免费网页竞品普遍不具备，核心心智占位；
2. **内容库**：课标会写字表（公开标准）+ 精选古诗（公有领域）+ 自定义课文粘贴，一键成帖；
3. **多模式**：描红（浅灰/轮廓、浓度可调）/ 临写空格 / 笔顺分解 / 纯格线纸；
4. **离线隐私 + 买断 ¥6**：低于一本字帖册，无限按需生成。

## 6. 技术方案

### 6.1 架构（核心 / UI 分离，核心 100% 纯函数可测）
```
entry/src/main/ets/
  core/                       ← 纯逻辑层（不 import ArkUI；hypium 直测）
    CopybookLayout.ets        ← 版面引擎：字列表+LayoutSpec → 逐页格矩阵坐标（纯函数）
    StrokeData.ets            ← 笔顺数据加载/查询（rawfile zlib JSON → 内存索引）
    PinyinData.ets            ← 读音表查询 + 多音字候选
    StrokeRender.ets          ← 笔画路径 → 位图指令：完整字/描红(浅灰填充/描边轮廓)/逐笔递进
    ContentLib.ets            ← 字表/古诗内容库（内置静态数据 + 校验和自检）
    SheetStore.ets            ← 历史持久化（配置物化，含字列表快照）
    PdfCodec/                 ← 移植 PdfComposer（自有 250 行）：位图页 → PDF 容器
  pages/
    HomePage.ets              ← 生成器表单（内容/模式/格型）
    PreviewPage.ets           ← 预览 + 导出
    SingleCharPage.ets        ← 单字专项
    HistoryPage.ets           ← 历史
  components/                 ← 格型选择器 / 拼音修正 chips / 进度遮罩
```

### 6.2 笔顺数据管线（关键技术点①：MIT 数据裁剪与降级）
- 数据源：Make Me a Hanzi（GitHub，MIT License）graphics.txt——每字 `strokes[]`（笔画中线路径，笔顺即数组顺序）；开发期 Python 预处理脚本裁剪常用 3500 字（覆盖课标字表全量）→ 单一 JSON → zlib 压缩 → rawfile（预期 < 2MB）；
- 渲染：笔画路径缩放至格内字面框（300dpi 下 path 抗锯齿填充）；描红 = 浅灰填充（浓度 3 档）或描边轮廓；笔顺帖 = 前 k 笔实色 + 其余淡出，每格递进；
- **降级协议**：数据缺失字（生僻字/扩展区）→ 描红/临写回退系统楷体字体渲染，笔顺帖该字跳过并计入提示条——绝不阻塞整帖生成；
- 开源声明：About 页 + AGC 提审材料标注 MIT 来源。

### 6.3 版面与渲染（关键技术点②：格矩阵纯函数布局）
- 版面引擎纯函数：输入（字列表 + LayoutSpec{格型/每行格数/模式/拼音开关/页眉开关/页尺寸 2480×3508px}）→ 输出每字 (页号, x, y) 坐标 + 笔顺分解子格布局——黄金用例直测（坐标快照）；
- 模式差异在布局层消解：描红帖 = 描格:空格 1:N 排列；笔顺帖 = 每字展开为 笔画数+1 格（逐笔递进 + 完整字收尾）；纯格纸 = 空格矩阵；
- 格线渲染：drawing（@ohos.graphics.drawing）外框实线 + 十字/对角虚线（沿用生字卡格线规范：900px 基准格线样式）；拼音行高联动字格；
- 每页 A4@300dpi 位图 → PNG → PdfComposer 合成 PDF（口算题卡项目同款管线，第三次复用）；
- 内存控制：逐页"渲染 → 编码 → 释放"，峰值单页 ≈ 35MB（RGBA），20 页导出预算 < 5s（进度条遮罩）。

### 6.4 内容库与校验
- 课标会写字表：教育部课程标准公开字表（一/二年级分表），按拼音排序内置（JSON + 校验和自检：加载时断言字数/无重复）；**不做教材课次对齐**（依赖教材版本版权，P2 查证后再议）；
- 精选古诗 30 首：公有领域（唐诗原文），M4 逐首人工校对入库（标题/作者/全文/生字关联）；
- 拼音表：常用 3500 字读音（含多音字候选集），与笔顺数据字集对齐；校验：字表每字必有读音，缺失即构建期告警。
