## 二、P1：本版本功能开发

### 1. 语速调节（1.3.2 需求 #6）

**现状**：`TtsUtil.ets` startSpeak 中 speed=1/volume=2/pitch=1 写死，跟读、背诵场景对 0.75x/1.5x 有实际需求。

**方案**：
- 播放页控制栏增加语速入口（当前"1.0x"文字按钮），点击弹出档位选择（0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x）；
- 档位持久化到 preferences（key: `reading_speed`），进入播放页自动恢复；
- `TtsController.startSpeak` 的 speakParams.speed 改为注入值，pause/resume 后保持；
- **朗读中切速即时生效**：当前句以新语速重读（句级重启，与暂停恢复粒度一致）。

**验收**：
- [ ] 六档语速真机可听出明显差异；
- [ ] 切速后暂停/恢复、跨条目播放均保持所选语速；
- [ ] 退出重进播放页档位保持。

**预估**：1 天（含真机试听各档位）

### 2. 逐句点读（1.3.2 需求 #9）

**现状**：播放页内容预览区（1.3.2 已落地分段高亮）仅展示，不可交互；`speakSegmented` 已支持任意起点，仅缺 `startFrom(index)` 暴露。

**方案**：
- `TtsController` 新增 `startFrom(index)`：校验分段模式与边界，停当前句、从指定句重启；
- 预览区每个分句可点击：朗读中点击=跳转起点，暂停/空闲时点击=从该句开始朗读；
- 点击后高亮立即移动到目标句。

**验收**：
- [ ] 任意状态下点击任意分句，从该句开始朗读且高亮正确；
- [ ] 点击越界/异常输入不崩溃；
- [ ] 跨条目播放时点读不串条目。

**预估**：0.5 天

### 3. "已加入清单"反馈增强（1.3.2 需求 #7）

**现状**：加入成功仅 toast"已添加到朗读清单"1000ms（`AddToReadingListUtil.ets:29`），不带清单名，确认感弱。调用方 3 处：PoemContentPage / XiehouyuQueryPage / DetailModal（成语）。

**方案**：
- 提示文案带清单名："已加入「每日诗词」"，时长 1000ms→1500ms；
- 重复加入提示同步优化："已在「每日诗词」中"。

**验收**：
- [ ] 三处详情页（诗词/歇后语/成语）加入成功 toast 均带清单名且 1500ms；
- [ ] 重复加入提示带清单名。

**预估**：0.25 天

- 1.3.1 基线（分段连读、按钮态、暂停保持、AVSession 后台、清单跨页刷新）不得回退；
