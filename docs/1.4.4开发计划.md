### 2.1 P0-1：文案海报 9:16 长图规格
| 项 | 内容 |
|---|---|
| 规格 | 长图 1080×1920（9:16），场景：朋友圈全屏、视频号封面、竖版海报 |

| 导出 | 组件快照管线复用，导出像素精确 1080×1920 |
| 历史 | ratio 随历史记录存储，旧记录向后兼容 |

### 2.2 P1-5：文案海报拼音注音开关
| 项 | 内容 |
|---|---|
| 入口 | 样式区新增「注音」开关 chip，默认关；随历史记录存储 |
| 引擎 | 复用 autoPinyin（array 模式，仅汉字注音；拉丁/数字/emoji 不注，与 bafcf69 行为一致） |

## 4. 交互与 UI 需求
- 切换规格**保留内容与全部样式选择**（与模板切换行为一致）；
- 9:16 预览在窄屏（≤600vp）下保证编辑区可见高度不压缩；
- 注音开关切换即时生效，预览无闪烁；关闭后字号恢复；
- 导出中 loading + 防重复点击（沿用现有）；
- 新增 UI 文案三语 `$r` 化。

## 5. 技术方案概要
- 9:16：`CopyPosterTemplates.ets` 比例定义增 900×1600；尺寸 chip 数据驱动扩展；预览/导出共用渲染组件自动适配（导出与预览同管线，杜绝预览≠导出）；
- 注音：`CoverContentUtil.autoPinyin` 复用；预览侧按行拆分主文案 → 逐行注音 → 行内 Text+拼音双行结构；字号预算公式 `textSize ≤ availH / (lines × (1 + pyRatio × 1.3))` 类推；
- 节气/节日模板：候选稿用纯 HTML/CSS 静态稿（同 T5-T15 候选文件范式），定稿后迁移至 `CopyPosterPreview.ets` Builder + `CopyPosterTemplates.ets` 定义；
- 版本与资源：`AppScope/app.json5` 三字段；`string.json` ×3 新键。
