# 1.3.4 版本开发计划：多语言支持

> 基线：v1.3.3（versionCode 1000013 @ c409f13）
> 决策（已确认）：1.3.3 完成既定任务；**1.3.4 直接支持多语言**（中文 + 英文）。

---

## 一、方案总览

- **资源结构**：`resources/base/element/string.json` = 英文（兜底，未匹配语言一律回退英文）；
  `resources/zh/element/string.json` = 简体中文（`zh` 限定词目录匹配所有中文变体 zh-CN/zh-TW/zh-HK，行为与现状一致）。
  AppScope `app_name` 同步拆分；应用名（品牌）两种语言均保留「解语珠玑」，如需英文名后续单改。
- **引用方式**：UI 层 `Text($r('app.string.key'))`；带参数用位置占位符 `%1$s`/`%1$d`；
  逻辑层（工具类）用 `StrUtil.text(context, $r(...))`（内部 `resourceManager.getStringSync`）或 `getStringByNameSync`。
- **ToastUtil** 入参放宽为 `ResourceStr`，toast 文案可直接传 `$r()`。
- **语言切换**：跟随系统语言，无需应用内切换器（1.3.5 视反馈再加）。

## 二、翻译范围（UI 文案全量）

**翻译**：页面标题/按钮/标签/toast/对话框/占位符/无障碍文本/空态、首页工具入口名称、
模板与配色名称、成就名称与描述、提醒与卡片文案、module.json5 标签与权限理由等全部用户可见 UI 文案。
盘点：约 1200 处引用、900+ 唯一串、42 个文件。

**不翻译（内容与数据域，保持中文）**：
1. 诗词/成语/歇后语内容本体（数据文件）；
2. 词云中文分词停用词表（KeywordUtil，语言学数据）；
3. 分享图装饰文案（干支、星期——中文内容产品的一部分，ShareImageUtil）；
4. 字体名称（思源黑体/霞鹜文楷等，字体标识符而非展示文案）；
5. 模板内示例文本（词云示例词、封面示例标题等，默认编辑内容）；
6. 单位名称与时区城市名（数据域，随数据评估，1.3.5）；
7. 数独 OCR / GIF 解析内部诊断信息（不面向用户）。

## 四、验收标准

- [ ] 系统语言英文：核心页面（首页/查询/详情/收藏/朗读/我的）无残留中文 UI 文案；
- [ ] 系统语言中文（含繁体）：显示与 1.3.3 一致，无回归；
- [ ] 其他语言（如法語）：回退英文；
- [ ] 键位审计脚本通过：base 与 zh 键集合完全一致，代码中 `$r` 引用键全部存在；
- [ ] 构建通过，真机双语言过核心回归主线。

## 五、不做（本版本）

- 应用内语言切换器（跟随系统）；
- 单位/城市数据、内容本体的翻译；
- RTL 语言支持。
