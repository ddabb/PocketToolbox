## 1. 背景与目标

「口袋工具箱」当前全部功能均为纯本地基础实现，尚未使用鸿蒙生态独有能力。基于《鸿蒙特性机会点分析》，本文档规划将鸿蒙系统特性分批融入现有功能，目标：

1. **提升交互质感**：关键操作加入触觉反馈（振动）；
2. **提升粘性**：利用系统级后台代理提醒，实现应用未运行也可触达的每日签到提醒；
3. **补齐核心体验**：朗读功能支持锁屏/控制中心/耳机线控控制与后台连续播放；
4. **打造差异化亮点**：拍照/选图 OCR「识诗」，端侧识别诗词文本一键搜索。

约束（与 GIF 制作器需求文档一致）：

- 目标环境：HarmonyOS 6.1.0（HUAWEI Pura 70 Pro+），API 6.1.1（24）；
- 全部新增能力均为**端侧/本地**实现，不引入网络依赖与云端服务；
- 新增权限全部为 normal 级别（VIBRATE / PUBLISH_AGENT_REMINDER / KEEP_BACKGROUND_RUNNING），无 ACL、无签名限制；
- 遵循现有代码模式：`getUIContext().getHostContext() as Context`、preferences(`app_cache`) 同步读写、ToastUtil、UI 验收清单制。

## 3. 第一期需求详述

### 3.1 H1 振动反馈（F-H1）

**需求**：关键交互节点加入短振动，强度分级：

| 编号 | 场景 | 触发点 | 时长 | usage |
| --- | --- | --- | --- | --- |
| H11 | 签到成功 | Index.doCheckIn 成功分支 | 30ms | touch |
| H12 | 每日挑战答题正确 / 错误 | DailyChallengePage.onOptionSelect | 15ms / 50ms | touch |
| H13 | 每日挑战完成 | DailyChallengePage.nextQuestion 完成分支 | 30ms | touch |
| H14 | 数独解题成功 / 无解或失败 | SudokuSolverPage.solve | 30ms / 50ms | touch |
| H15 | GIF 导出成功 / 失败 | GifMakerPage.startExport 回调 | 30ms / 50ms | touch |

**技术方案**：新增 `common/utils/VibrateUtil.ets`：

- `VibrateUtil.tap()`（15ms）/ `VibrateUtil.success()`（30ms）/ `VibrateUtil.error()`（50ms）；
- 内部调用 `vibrator.startVibration({ type: 'time', duration }, { usage: 'touch' })`，Promise 失败静默（无振动马达场景不崩溃、不打日志噪音）。

**验收标准**：

- [ ] 签到成功有一次短振；
- [ ] 挑战答题正确轻振、错误重振、完成短振；
- [ ] 数独解出短振、失败重振；
- [ ] GIF 导出成功短振、失败重振；
- [ ] 不支持振动的设备上无崩溃、无报错弹窗。

### 3.2 H2 每日签到提醒（F-H2）

**需求**：

| 编号 | 需求 |
| --- | --- |
| H21 | 「关于」页新增「每日签到提醒」开关行，默认关闭； |
| H22 | 开启时先请求通知授权（`notificationManager.requestEnableNotification`），授权成功后发布系统日历提醒：每天 20:00，「解语珠玑」——今天还没签到打卡，每日挑战等你来战； |
| H23 | 应用退出的场景下提醒照常触发（后台代理提醒由系统托管）；点击提醒拉起应用； |
| H24 | 关闭开关即取消已发布提醒；通知授权被永久拒绝时，调用 `openNotificationSettings` 引导用户去系统设置开启，开关回退为关； |
| H25 | 开关状态与已发布提醒 ID 持久化在 preferences（`app_cache`），重启应用后保持。 |

**技术方案**：新增 `common/utils/CheckInReminderUtil.ets`：

- `isOn(context)` / `enable(context): Promise<boolean>` / `disable(context): Promise<void>`；
- 使用 `reminderAgentManager.ReminderRequestAlarm`（hour=20, minute=0, daysOfWeek=[1..7] 每日重复）；
- wantAgent 指向 EntryAbility，点击通知打开应用；
- 已发布 reminderId 存 preferences，disable 时 `cancelReminder(id)`。

**验收标准**：

- [ ] 首次开启弹出系统通知授权弹窗，允许后开关保持开启；
- [ ] 开启后退出的应用，20:00 收到系统提醒；
- [ ] 点击提醒拉起应用；
- [ ] 关闭开关后不再收到提醒；
- [ ] 拒绝授权时开关自动回退，并跳转系统通知设置页。

### 3.3 H3 朗读后台播放（F-H3）

**需求**：

| 编号 | 需求 |
| --- | --- |
| H31 | 朗读播放页开始朗读时创建 AVSession（audio 类型）并激活；锁屏、控制中心、耳机线控可控制 播放/暂停/上一条/下一条； |
| H32 | 播放期间申请 AUDIO_PLAYBACK 连续任务（长时任务），应用退到后台朗读不中断； |
| H33 | 媒体控制界面显示当前朗读条目标题（元数据 title）与来源（解语珠玑·朗读清单）；切换条目时更新； |
| H34 | 停止朗读、退出播放页时：AVSession 置 pause → destroy，取消连续任务； |
| H35 | 控制中心操作与页面内操作状态双向一致（控制中心暂停后页面按钮状态同步）。 |

**技术方案**：新增 `common/utils/ReadingAvSession.ets`（封装 AVSession + 长时任务）：

- `start(context, onPlay, onPause, onNext, onPrev)`：`avSession.createAVSession(context, 'ReadingTTS', 'audio')` → setAVMetadata → activate → on('play'/'pause'/'playNext'/'playPrevious'/'stop') → `backgroundTaskManager.startBackgroundRunning(context, BackgroundMode.AUDIO_PLAYBACK, wantAgent)`；
- `updateTitle(title)`：setAVMetadata 更新；
- `setPlaying(playing)`：setAVPlaybackState（PLAYBACK_STATE_PLAY / PLAYBACK_STATE_PAUSE）；
- `stop()`：destroy + stopBackgroundRunning。

**module.json5 变更**：ability 增加 `"backgroundModes": ["audioPlayback"]`；requestPermissions 增加 `ohos.permission.KEEP_BACKGROUND_RUNNING`。

**已知限制**：TTS 引擎（CoreSpeechKit）无暂停/恢复接口，控制中心「暂停」实现为停止当前条目，再点「播放」从头朗读当前条目（与页面内行为一致）。

**验收标准**：

- [ ] 开始朗读后锁屏可见媒体卡片，标题正确；
- [ ] 锁屏点暂停，页面按钮同步为「播放」；点播放继续朗读；
- [ ] 退到后台朗读不中断（连续任务通知存在）；
- [ ] 退出播放页后锁屏媒体卡片消失、连续任务取消。

### 3.4 H4 拍照识诗（F-H4）

**需求**：

| 编号 | 需求 |
| --- | --- |
| H41 | 诗词查询页搜索栏新增「📷 识诗」按钮； |
| H42 | 点击后拉起系统相册（PhotoViewPicker）选一张图片； |
| H43 | 端侧 OCR（Core Vision Kit textRecognition）识别图中全部文本行；识别中显示 Loading； |
| H44 | 识别完成弹出底部候选面板：展示识别出的文本行（过滤空白行，长度 2~40 字，去重，最多 20 行）； |
| H45 | 点击任意一行：填入搜索框、自动执行搜索、关闭面板； |
| H46 | 识别失败或无有效文本时 Toast 提示；用户取消选择图片不产生任何提示。 |

**技术方案**：新增 `common/utils/OcrUtil.ets`：

- `OcrUtil.recognizeLines(pixelMap): Promise<string[]>`：`textRecognition.recognizeText({ pixelMap })` → 遍历 blocks[].lines[] 收集 value，trim、过滤、去重、截断；调用方负责 PixelMap 创建与释放；
- PoetryQueryPage：SearchBar 增加 📷 按钮；新增 `@State ocrSheetVisible/ocrLines/ocrLoading`；选图沿用项目内 fileIo.openSync(uri) → image.createImageSource(fd) → createPixelMap 模式。

**验收标准**：

- [ ] 选中含诗句的图片后候选面板列出诗句行；
- [ ] 点某行后搜索框填充并立即出结果；
- [ ] 选图取消无任何 UI 变化；
- [ ] 无文字图片提示「未识别到文本」。

## 5. 测试与验收策略

- 每个 util 先行 `arkts_check` 静态校验，随后 hvigorw 全量构建；
- H1/H3/H4 逻辑简单不引入纯函数新算法，不新增本地单测（振动/AVSession/OCR 均为系统能力封装，单测无意义）；
- 真机验收清单见各节「验收标准」，由用户在 Pura 70 Pro+ 上逐项勾选。
