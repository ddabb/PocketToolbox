# 变现能力开发计划（个人开发者 · 整包付费版）

| 版本 | 日期 | 说明 |
| --- | --- | --- |
| v1.0 | 2026-09-13 | 初稿：广告 + 买断 + 订阅三层结构（基于"广告可行"假设） |
| v2.0 | 2026-09-15 | 重构为「个人开发者 · 整包付费」单一路径。原因：个人开发者无法接入华为广告变现（鲸鸿动能，需企业主体），广告层与"去广告 Pro"卖点均不成立；经决策选定整包付费下载模式，移除全部广告/IAP/订阅相关内容 |

## 1. 目标与范围

将「口袋工具箱」（HarmonyOS ArkTS 应用，包名 `com.ddabb.toolbox`）从**免费应用切换为整包付费下载**（AppGallery `Payment type = Paid`）。用户安装前一次性付费，开发者赚取下载费。

**本期目标**：
1. 开通商户服务（个人开发者，绑银行卡结算）；
2. AGC 配置付费应用：设基础价格、税率、按汇率换算海外价；
3. 安装包开启加密、确认 API 版本 > 10，构建可上架加密包；
4. 提交付费版本过审，完成付费分发闭环；
5. 平稳过渡存量用户（已装用户免费升级）。

**不适用（个人开发者硬约束）**：
- 广告变现（鲸鸿动能 / Ads Kit 流量变现）——需企业主体，个人开发者不可行；
- 应用内购买（IAP 非消耗型买断 / 自动续期订阅）——本期不做（如需功能买断需另立方案，且商品卖点须为"功能解锁"而非"去广告"）。

**代码改动说明**：整包付费是**分发层配置**，应用内无需权益判断逻辑（安装即付费用户），故**代码改动极小**，主要工作量在 AGC 管理与打包加密。

## 3. 总体分期

| 阶段 | 内容 | 依赖 | 产出 |
| --- | --- | --- | --- |
| **P0 管理侧配置** | 商户服务开通、AGC 付费应用设置（价格/税率/币种）、隐私政策 URL | D1~D4 决策 | 付费应用就绪、隐私 URL |

| **P3 存量过渡** | 更新日志公告"老用户免费升级"、分阶段发布灰度、监控转化与评分 | P2 | 平稳切换、数据基线 |

## 4. 技术要点（整包付费硬性要求）

依据华为开发者联盟付费应用规则：

1. **包的 API 版本必须 > 10**（纯血鸿蒙默认满足）。
2. **安装包必须设置为需要加密（require encryption）**：
   - FA 模型不支持加密 → FA 应用无法设付费；
   - 本项目为 ArkTS **Stage 模型**，支持加密，OK。
3. **发布类型须为测试 / 分阶段发布 / 全量发布**（不能是仅草稿）。
4. 若旧版本已 `Released` 且包未加密：**不能**直接设付费，须新建版本、重打加密包、发布后再设付费。
5. **应用内代码**：无需新增支付/权益逻辑；安装用户即付费用户，无需 `PayUtil` / `EntitlementUtil` 之类组件。

## 5. 管理侧（AGC）配置清单

| # | 平台 | 操作 | 产出 / 前置 |
| --- | --- | --- | --- |
| 1 | 开发者联盟 管理中心 | 实名认证（个人）→ **商户服务**开通：签署协议、绑定结算银行卡、税务信息 | 付费分发硬前置，未开通则无法设付费 |
| 2 | AGC → 我的项目 → 定价与分发 | `Payment type = Paid`；设基础价格（默认含税）→ 选币种（CNY 起步）→ 选目标国家/地区 → 系统按汇率+税率自动换算本地价 | 付费价格生效 |
| 3 | AGC → 应用内容 | 隐私政策 URL 更新：披露支付订单数据处理方为华为；同步"权限使用说明" | 审核硬要求；依赖 D3 |
| 4 | AGC → 版本管理 | 上传加密包 → 设付费 → 提交审核 | 上架后正式生效 |
| 5 | AGC → 版本管理（可选） | 分阶段发布（phased release）灰度切付费，观察转化与评分 | 降低一刀切风险 |

注意：华为每日更新汇率但**不会自动更新已保存价格**，如长期运营需手动刷新价格。

## 6. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 盲付转化低 | 下载量 / 收入不及预期 | ¥6 低价切入；优化 ASO 标题/关键词/截图；可先免费积累评分再切付费 |
| ARPU 天花板 | 单次 ¥6，无持续收入 | 接受一次性模型；未来如需持续收入可评估转「免费 + IAP 功能买断」（需重做方案） |
| 存量用户口碑 | 老用户见收费刷差评 | 公告"已装用户免费升级"；更新日志明确说明；分阶段灰度 |
| 质量分 < 4.0 限制付费上架 | 无法设付费 | 先修崩溃/差评，提分到 4.0+ 再切 |
| 加密包审核更严、周期 +3~5 天 | 上架延期 | 预留时间，材料一次备齐（隐私政策、权限说明） |
